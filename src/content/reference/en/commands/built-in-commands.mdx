title: Built-in commands
description: See every command the bot ships with, what each one answers, and how to change or reset its reply, role and cooldowns.
---

A built-in command is a command the bot ships with, such as `!uptime`.
Every channel has the same set, and you cannot delete one.
You find them on the **Commands** page in the sidebar, on the **System commands** tab.

The tab shows only to someone who may change commands.
Who that is, and how to make your own commands, is on [Create a command](/reference/commands/create-a-command).

## The list

The **Built-in commands** list shows one row per command, with a search box, **Search commands**.
Each row shows the trigger, who may use it and its cooldowns, for example "Everyone · 30s chat · 0s each".
A cooldown is how long chat waits before the command answers again (see [Cooldowns and permissions](/reference/commands/cooldowns-and-permissions)).

| Row text | What it means |
| --- | --- |
| **Using the default** | The channel has not changed the role or a cooldown. |
| **Overrides the default (...)** | The channel changed the role or a cooldown. The brackets hold the default. |
| **Always on · ...** | No channel can switch the command off. The row has no switch. |
| **This is a data-rights command. It always answers and its settings are fixed.** | A command that lets a viewer see or remove their own data. Nothing on it can change. |

## Switch a command on or off

Each row has a switch, except a command that is always on.
The editor has the same switch, **Answers in chat**.
Both save at once.

A command that is off is ignored in chat, the same as a word that is no command.
The bot refuses to switch a command off while a reward, timer or other item still runs it.

## Every built-in command

The bot has 42 built-in commands.
The table lists all 42 from A to Z, with the defaults the editor shows.
A default of 0 seconds means no cooldown.

| Command | What it does | **Who can use it** | Chat cooldown | Per-person cooldown |
| --- | --- | --- | --- | --- |
| `!accountage` | Answers how old the caller's Twitch account is. | Everyone | 0 s | 30 s |
| `!allow` | `!allow massban` lets a held mass ban run now (see [Bans and blocked terms](/reference/moderation/bans-and-blocked-terms)). | Lead moderators | 3 s | 0 s |
| `!banger` | Adds the playing song to the channel's banger playlist. | Everyone | 5 s | 0 s |
| `!bansong` | Blocks the playing song from later requests. | Everyone | 5 s | 0 s |
| `!clearsongs` | Removes every queued song of one viewer. | Everyone | 5 s | 0 s |
| `!closequeue` | Stops new song requests. The music keeps playing. | Everyone | 5 s | 0 s |
| `!coinflip` | Plays a coin flip for a bet in channel currency. | Everyone | 0 s | 0 s |
| `!commands` | Lists the channel's commands that are switched on. | Everyone | 15 s | 0 s |
| `!dice` | Plays a dice roll for a bet in channel currency. | Everyone | 0 s | 0 s |
| `!disallow` | `!disallow massban` stops a held mass ban. | Lead moderators | 3 s | 0 s |
| `!discord` | Answers an invite link to the channel's Discord server (see [Discord](/reference/integrations/discord)). | Everyone | 30 s | 0 s |
| `!followage` | Answers how long the caller has followed the channel. | Everyone | 0 s | 30 s |
| `!forgetme` | Removes the caller's own data, after a second confirm. Data-rights command. | Everyone | 0 s | 0 s |
| `!gdpr` | `!gdpr status`, `!gdpr forget` and `!gdpr export`. Data-rights command. | Everyone | 0 s | 0 s |
| `!help` | Answers how to use a command, for example `!help sr`. | Everyone | 15 s | 0 s |
| `!leaderboard` | Answers the top of the channel's leaderboard (see [Leaderboards and games](/reference/economy/leaderboards-and-games)). | Everyone | 10 s | 0 s |
| `!lurk` | Marks the caller as lurking (watching without chatting). | Everyone | 0 s | 30 s |
| `!media` | Sends a clip or video link to media share (see [Media share](/reference/audio/media-share)). | Everyone | 0 s | 0 s |
| `!mydata` | Asks for a copy of the caller's own data. Data-rights command. | Everyone | 0 s | 0 s |
| `!openqueue` | Takes new song requests again. | Everyone | 5 s | 0 s |
| `!pause` | Pauses the music. | Everyone | 5 s | 0 s |
| `!permit` | Gives a viewer a role or a right for a time. Always on. | Moderators | 0 s | 0 s |
| `!playlist` | Answers the link to the channel's banger playlist. | Everyone | 10 s | 0 s |
| `!profile` | The same answer as `!stats`. | Everyone | 0 s | 10 s |
| `!queue` | Lists the song queue, or the caller's own requests. | Everyone | 0 s | 10 s |
| `!quote` | Shows a random quote, or a quote by number. It also adds, edits and deletes quotes (see [Quotes](/reference/commands/quotes)). | Everyone | 5 s | 0 s |
| `!resume` | Plays the music again. | Everyone | 5 s | 0 s |
| `!skip` | Skips the playing song. A viewer can skip only a song they requested. With a number, it removes the caller's own queued request. | Everyone | 5 s | 0 s |
| `!slots` | Plays the slots for a bet in channel currency. | Everyone | 0 s | 0 s |
| `!song` | Answers which song plays now. | Everyone | 10 s | 0 s |
| `!sr` | Requests a song for the queue (see [Song requests](/reference/music/song-requests)). | Everyone | 0 s | 5 s |
| `!stats` | Answers a viewer's channel stats. | Everyone | 0 s | 10 s |
| `!unlurk` | Clears the caller's lurking mark. | Everyone | 0 s | 30 s |
| `!unpermit` | Takes a given role or right back. Always on. | Moderators | 0 s | 0 s |
| `!unwhitelist` | Takes back the standing that `!whitelist` gives. | Only you | 0 s | 0 s |
| `!update` | Reads the caller's Twitch name and avatar again. A moderator may name another viewer. | Everyone | 0 s | 60 s |
| `!uptime` | Answers how long the stream has been live. | Everyone | 30 s | 0 s |
| `!voice` | Lets a viewer pick their own text-to-speech voice (see [Text to speech](/reference/audio/text-to-speech)). | Everyone | 0 s | 5 s |
| `!volume` | Answers or sets the music volume. | Everyone | 5 s | 0 s |
| `!whisper` | Sends a viewer a private message from the bot. | Moderators | 0 s | 3 s |
| `!whitelist` | Gives a viewer the standing of a subscriber, VIP or moderator for commands. | Only you | 0 s | 0 s |
| `!wrongsong` | Takes back the caller's own song request. | Everyone | 0 s | 5 s |

`!pause`, `!resume`, `!volume` with a number, `!bansong`, `!closequeue`, `!openqueue` and `!clearsongs` check the caller again when they run, and a moderator passes.
Anyone else passes only when the broadcaster gave them the right to moderate the song queue.
`!skip` with no number lets a moderator or a holder of that right skip any song.

Data-rights commands are explained on [Your data and privacy](/reference/settings/your-data-and-privacy).

### Ask by whisper

`!uptime`, `!song` and `!queue` also answer a whisper (a private message) to the bot.
The answer comes back as a whisper, never in chat.
Every other built-in command answers a whisper with "works in chat only."

## Change a built-in command

1. Choose the command in the list.
   The editor opens with the command name at the top and **Built-in** under it.
   The fields show the defaults and are locked: "These are the defaults. Customize to make them your own; each change overrides the default."
2. Choose **Customize** in the footer.
   The fields unlock.
3. Change the fields you want.
   The footer counts them, for example "2 unsaved changes".
4. Choose **Save changes**.
   The count leaves the footer.
   Each changed field shows **Overrides the default (...)** with the default in the brackets.

**Discard** in the footer puts every field back as it was saved.
A command that has saved changes opens unlocked next time.

| Field | What it sets | Limits |
| --- | --- | --- |
| A reply box per reply | The words of one reply the command sends. Its label names the moment, such as a success or a refusal. | Up to 500 characters. |
| **Who can use it** | The lowest role that may run the command. | The list starts at the command's default role. You can raise it, never lower it. |
| **Chat cooldown (seconds)** | How long all of chat waits between uses. | 0 to 3600 seconds. |
| **Per-person cooldown (seconds)** | How long one viewer waits between uses. | 0 to 3600 seconds. |
| **Read it aloud** | Also speaks the reply with text to speech. | Default: Off. Only `!quote` speaks its reply. |

### Write a reply

A reply box holds the line the bot types in chat, in the channel's one bot voice.
Until you change it, the box shows the default wording.
The default wording follows the bot's personality on [Bot basics and personality](/reference/settings/bot-basics-and-personality).

A helper is a name in braces that the bot fills in before it sends the line.
Under the box, **Variables:** lists the values only this command's reply can use, such as `{stats.points}` and `{stats.watchtime}` for `!stats`.
The helpers every reply can use are on [Variables and templates](/reference/commands/variables-and-templates).

A reply of a data-rights command shows "This reply is fixed and cannot be changed."

`!lurk` and `!unlurk` share their replies.
`!stats` and `!profile` share theirs too.
A change to a shared reply shows on both commands.

## Put one field back

A changed field has a **Back to default** button under it.
It saves at once, with no **Save changes**.
The field shows its default again, and the hint reads **Using the default**.

## Reset a command to its default

1. Open the command in the list.
2. Choose **Reset to default** in the footer.
   The dialog asks "Reset !name to its default?": "These settings go back to the platform default. Your edits to them are lost."
   It lists what goes back, for example **Chat cooldown** or **Reply wording**.
3. Choose **Reset to default** in the dialog.
   Every field shows its default, and the command is switched on.

| Item in the dialog | What goes back |
| --- | --- |
| **Chat cooldown** | The default chat cooldown. |
| **Per-person cooldown** | The default per-person cooldown. |
| **Who can use it** | The default role. |
| **Reply wording** | The default words of every reply. |
| **Read aloud** | **Read it aloud** turns off. |
| **Turned back on** | The command answers in chat again. |

**Reset to default** shows only when something differs from the default.
A data-rights command has no **Reset to default** button.
For a command that shares its replies, a reset also puts the shared replies back on the other command.

## Troubleshooting

::Troubleshooting

**A built-in command does nothing in chat.**
Check these, in order:

1. The switch in the list. A command that is off answers nobody.
2. Whether the stream is live. Offline, viewer commands do nothing unless **Keep commands and rewards on while offline** is on (see [Bot basics and personality](/reference/settings/bot-basics-and-personality)). Moderators, you and data-rights commands always get an answer.
3. **Who can use it**. The viewer's role must be at least the role shown.
4. The **Chat cooldown (seconds)** and the **Per-person cooldown (seconds)**.
5. A channel command with the same name. It answers instead of the built-in command, except for `!permit`, `!unpermit` and the three data-rights commands (`!mydata`, `!gdpr`, `!forgetme`). These five always answer as the built-in command (see [Create a command](/reference/commands/create-a-command)).

::
