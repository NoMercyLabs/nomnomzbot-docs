Helpers on this page: `{fun.*}`.

These helpers play small games, such as dice, a coin flip and the 8-ball.
Most give a different result each time, so the example shows one possible result.

Each row is its own example, so the rows on this page do not all come from one moment.

| Helper | What it gives | Example |
| --- | --- | --- |
| `{fun.8ball}` | One answer from your own pick list named 8ball | `It is certain` |
| `{fun.card}` | Draws a playing card from a deck of 52 | `Q♥` |
| `{fun.coin}` | Flips a coin: heads or tails | `heads` |
| `{fun.coin.emoji}` | Flips a coin and shows it with a coin emoji | `🪙 heads` |
| `{fun.countdown}` | Counts down from your number to 1 (up to 20) | `{fun.countdown:3}` gives `3… 2… 1…` |
| `{fun.dice}` | Rolls dice and gives the total. With no input it rolls one six-sided die. A number is one die with that many sides (2 to 1000), and 2d6 is two six-sided dice (up to 100 dice) | `{fun.dice:20}` gives `5` |
| `{fun.dice.detail}` | Rolls dice like 2d6 and shows every roll, then the total | `{fun.dice.detail:2d6}` gives `2 + 1 = 3` |
| `{fun.dice.emoji}` | Shows one die face, or as many as you ask for (up to 20) | `{fun.dice.emoji:3}` gives `⚁ ⚀ ⚂` |
| `{fun.flip}` | Flips a table and turns your text upside down | `{fun.flip:table}` gives `(╯°□°)╯︵ ǝlqɐʇ` |
| `{fun.lenny}` | A lenny face | `( ͡° ͜ʖ ͡°)` |
| `{fun.love}` | A love score from 0 to 100 percent for two names typed with a pipe between them, the same all day whichever name comes first | `{fun.love:{user.display}\|{target.display}}` gives `22%` |
| `{fun.meter}` | A progress bar with its percent, the same as meter | `{fun.meter:60}` gives `██████░░░░ 60%` |
| `{fun.percent}` | A percentage for something, the same all day for the same viewer and thing | `{fun.percent:luck}` gives `8%` |
| `{fun.random.animal}` | A random animal with its emoji | `🦊 fox` |
| `{fun.random.color.name}` | A random color name | `teal` |
| `{fun.random.emoji}` | A random party emoji from a fixed, safe set | `🎉` |
| `{fun.random.food}` | A random food with its emoji | `🍕 pizza` |
| `{fun.rate}` | Rates something from 1 to 10, the same all day for the same thing | `{fun.rate:pizza}` gives `8/10` |
| `{fun.roulette}` | Pulls the trigger: click, or bang one time in six | `click` |
| `{fun.rps}` | Picks rock, paper or scissors | `🪨 rock` |
| `{fun.rps.vs}` | Plays rock, paper, scissors against your choice and says who won | `{fun.rps.vs:rock}` gives `rock — a draw` |
| `{fun.ship}` | Blends two names, typed with a pipe between them, into a ship name | `{fun.ship:Alexander\|Bo}` gives `Alexander + Bo = Alexo` |
| `{fun.shrug}` | A shrug | `¯\_(ツ)_/¯` |
| `{fun.slots}` | Spins a slot machine with three reels | `🍒 🍋 🍒` |
| `{fun.slots.win}` | True when the last slot machine spin in this message matched on all three reels, otherwise false | `false` |
| `{fun.unflip}` | Puts the table back | `┬─┬ノ( º _ ºノ)` |
