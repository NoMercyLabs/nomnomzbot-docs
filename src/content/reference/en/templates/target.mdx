Helpers on this page: `{target}`, `{target.*}`.

The target is the person a command names, such as `@someone` in `!hug @someone`.
These helpers give the target's name, pronouns, account, stats and live status, such as `{target.name}` and `{target.subject}`.
Use them in a reply that talks about another person, such as a hug or a shoutout.

## Pronouns

The `target.` pronoun helpers sit in the first table below.
They read the saved pronouns of the person the command names.
To learn where the bot gets pronouns and how to write a reply that fits he, she and they, read [Pronouns in templates](/reference/templates/pronouns).

Each row is its own example, so the rows on this page do not all come from one moment.

## Pronouns and grammar

| Helper | What it gives | Example |
| --- | --- | --- |
| `{target.genderedTerm}` | A gendered term for the @mention target | `person` |
| `{target.object}` | The object-case pronoun for the @mention target | `them` |
| `{target.possessive}` | The possessive pronoun for the @mention target | `their` |
| `{target.presentTense}` | The present-tense to-be form for the @mention target | `are` |
| `{target.subject}` | The subject-case pronoun for the @mention target | `they` |
| `{target.tense}` | The live/offline-aware tense for the @mention target | `are` |
| `{target.verb:<sing\|plur>}` | A singular/plural verb agreeing with the @mention target (e.g. `{target.verb:plays\|play}`) | `{target.verb:has\|have}` gives `have` |
