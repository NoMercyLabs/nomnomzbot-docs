Helpers on this page: `{target}`, `{target.*}`.

The target is the person a command names, such as `@someone` in `!hug @someone`.
These helpers give the target's name, pronouns, account, stats and live status, such as `{target.name}` and `{target.subject}`.
Use them in a reply that talks about another person, such as a hug or a shoutout.

## Pronouns

The `target.` pronoun helpers sit in the first table below.
They read the saved pronouns of the person the command names.
To learn where the bot gets pronouns and how to write a reply that fits he, she and they, read [Pronouns in templates](/reference/templates/pronouns).

## Write a reply about someone else

For a command used as `!hug @someone`, try `{user} sends a hug to {target.displayname}.` as its reply.
The caller's name fills `{user}`, while the named person's display name fills `{target.displayname}`.
The bot can look up a Twitch account it has not seen in chat before; when that lookup fails, the display-name helper falls back to the word supplied.

Use a target-dependent reply for commands where viewers are expected to name someone.
A timer has no such caller or named person, which is why target helpers are not listed for timers in **Use in**.

The points helpers read the named person's balance in the bot's [channel currency](/reference/economy/currency-and-balances).
That balance is separate from Twitch Channel Points used for rewards and predictions.

The examples illustrate possible values; your results depend on the channel and trigger.
**Use in** lists the template fields that accept each helper.
A pipeline still needs a trigger that supplies the relevant person, message, or event; event-specific helpers need that event.
For viewer-written text, the [Viewer Templates setting and permissions](/reference/settings/features) also apply.

## Pronouns and grammar

| Helper | What it gives | Example | Use in |
| --- | --- | --- | --- |
| `{target.genderedTerm}` | A gendered term for the @mention target | `person` | Commands, event responses, pipelines, webhooks |
| `{target.object}` | The object-case pronoun for the @mention target | `them` | Commands, event responses, pipelines, webhooks |
| `{target.possessive}` | The possessive pronoun for the @mention target | `their` | Commands, event responses, pipelines, webhooks |
| `{target.presentTense}` | The present-tense to-be form for the @mention target | `are` | Commands, event responses, pipelines, webhooks |
| `{target.subject}` | The subject-case pronoun for the @mention target | `they` | Commands, event responses, pipelines, webhooks |
| `{target.tense}` | Is or are while your channel is live, was or were when it is offline. In a shoutout it follows the live state of the person shouted out instead | `are` | Commands, event responses, pipelines, webhooks |
| `{target.verb:<sing\|plur>}` | A singular/plural verb agreeing with the @mention target (e.g. `{target.verb:plays\|play}`) | `{target.verb:has\|have}` gives `have` | Commands, event responses, pipelines, webhooks |
