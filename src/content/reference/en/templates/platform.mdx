Helpers on this page: `{platform.*}`.

These helpers read the platforms the channel streams to, such as Twitch, Kick and YouTube.
Use them to show viewers and links for every platform.

The examples illustrate possible values; your results depend on the channel and trigger.
**Use in** lists the template fields that accept each helper.
A pipeline still needs a trigger that supplies the relevant person, message, or event; event-specific helpers need that event.
For viewer-written text, the [Viewer Templates setting and permissions](/reference/settings/features) also apply.

| Helper | What it gives | Example | Use in |
| --- | --- | --- | --- |
| `{platform.chatters.stream}` | The different chatters on one platform since the stream started, for example youtube: 6 | `{platform.chatters.stream:youtube}` gives `6` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.connected}` | The platforms the streamer connected: Twitch, Kick, YouTube | `Twitch, Kick, YouTube` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.count}` | How many platforms the streamer connected: 3 | `3` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.event}` | The platform the event came from: twitch | `twitch` | Commands, event responses, pipelines, webhooks, Discord |
| `{platform.followers.twitch}` | The Twitch follower count: 1,234 | `1,234` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.isLive}` | true when the platform is live now, for example youtube: true | `{platform.isLive:youtube}` gives `true` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.link.kick}` | The link to the Kick channel: https://kick.com/samplechannel | `https://kick.com/samplechannel` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.link.twitch}` | The link to the Twitch channel: https://twitch.tv/samplechannel | `https://twitch.tv/samplechannel` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.link.youtube}` | The link to the YouTube channel: https://youtube.com/channel/UCsample | `https://youtube.com/channel/UCsample` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.link.youtube.live}` | The link to the YouTube stream that is live now: https://youtube.com/watch?v=sample | `https://youtube.com/watch?v=sample` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.links}` | The links to every connected channel, without https: twitch.tv/samplechannel · kick.com/samplechannel | `twitch.tv/samplechannel · kick.com/samplechannel · youtube.com/channel/UCsample` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.live.count}` | How many platforms are live now: 3 | `3` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.live.list}` | The platforms that are live now: Twitch, Kick, YouTube | `Twitch, Kick, YouTube` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.messages.stream}` | The chat messages on one platform since the stream started, for example kick: 120 | `{platform.messages.stream:kick}` gives `120` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.title}` | The stream title on one platform, for example youtube: Building a bot | `{platform.title:youtube}` gives `Building a bot` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.top}` | The live platform with the most viewers: Twitch | `Twitch` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.user}` | The platform of the person who typed the command: twitch | `twitch` | Commands, event responses, pipelines, webhooks |
| `{platform.user.icon}` | The icon of that platform: a purple, green or red dot | `🟣` | Commands, event responses, pipelines, webhooks |
| `{platform.user.name}` | The display name of that platform: Twitch | `Twitch` | Commands, event responses, pipelines, webhooks |
| `{platform.viewers.breakdown}` | The viewers per live platform: Twitch 42 · Kick 10 · YouTube 8 | `Twitch 42 · Kick 10 · YouTube 8` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.viewers.kick}` | The viewers on Kick now: 10. Empty when Kick is not connected or not live | `10` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.viewers.share}` | The share of all viewers on one platform, for example kick: 17% | `{platform.viewers.share:kick}` gives `17%` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.viewers.total}` | The viewers on every live platform together: 60 | `60` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.viewers.twitch}` | The viewers on Twitch now: 42. Empty when Twitch is not live | `42` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{platform.viewers.youtube}` | The viewers on YouTube now: 8. Empty when YouTube is not connected or not live | `8` | Commands, event responses, timers, pipelines, Discord, webhooks |
