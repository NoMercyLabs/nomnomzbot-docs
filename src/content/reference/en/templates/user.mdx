Helpers on this page: `{user}`, `{user.*}`, `{viewer.*}`, `{engagement.*}`, `{name}`, `{link}`, `{subject}`, `{object}`, `{possessive}`, `{tense}`, `{presentTense}`, `{genderedTerm}`, `{verb:*}`.

These helpers are about the person who used the command, such as `{user}`, `{user.points}` and `{user.followAge}`.
They also hold that person's pronouns and the words that go with them, such as `{user.subject}` and `{user.possessive}`.
The bare helpers `{name}`, `{link}`, `{subject}`, `{object}`, `{possessive}`, `{tense}`, `{presentTense}`, `{genderedTerm}` and `{verb:plays|play}` are here too.
Use them to greet a viewer, to show their stats, or to write a reply that fits their pronouns.

`{user}` is the display name, written the way the viewer writes it.
In a chat reply, the bot writes the display name only when it matches the login apart from letter case. Otherwise, for example for a name in another alphabet, it writes the login.
`{user.name}` is the login name, in lower case.

## Pronouns

The pronoun and grammar helpers sit in the first table below.
To learn where the bot gets pronouns and how to write a reply that fits he, she and they, read [Pronouns in templates](/reference/templates/pronouns).

Each row is its own example, so the rows on this page do not all come from one moment.

## Pronouns and grammar

| Helper | What it gives | Example |
| --- | --- | --- |
| `{genderedTerm}` | A gendered term matching the person pronouns (e.g. guy/gal) | `person` |
| `{object}` | The object-case pronoun (e.g. them) | `them` |
| `{possessive}` | The possessive pronoun (e.g. their) | `their` |
| `{presentTense}` | The present-tense to-be form (e.g. is/are) | `are` |
| `{subject}` | The subject-case pronoun (e.g. they) | `they` |
| `{tense}` | The live/offline-aware tense (is/was) | `is` |
| `{user.genderedTerm}` | A gendered term for the triggering user | `person` |
| `{user.object}` | The object-case pronoun for the triggering user | `them` |
| `{user.possessive}` | The possessive pronoun for the triggering user | `their` |
| `{user.presentTense}` | The present-tense to-be form for the triggering user | `are` |
| `{user.pronouns}` | The triggering user recorded pronouns | `they/them` |
| `{user.subject}` | The subject-case pronoun for the triggering user | `they` |
| `{user.tense}` | The live/offline-aware tense for the triggering user | `are` |
| `{user.verb:<sing\|plur>}` | A singular/plural verb agreeing with the triggering user (e.g. `{user.verb:plays\|play}`) | `{user.verb:has\|have}` gives `has` |
| `{verb:<sing\|plur>}` | A singular/plural verb agreeing with the mirrored subject (e.g. `{verb:plays\|play}`) | `{subject} {verb:plays\|play}` gives `he plays` |

## Names and links

| Helper | What it gives | Example |
| --- | --- | --- |
| `{link}` | A profile link - the @mention target if present, otherwise the triggering user | `twitch.tv/example_viewer` |
| `{name}` | The name shown - the @mention target if present, otherwise the triggering user | `Example_Viewer` |
| `{user}` | The name of the person who used the command, as they write it (the display name). A chat reply uses the login when the two differ by more than letter case | `Example_Viewer` |

| `{user.bio}` | The profile description of the viewer | `I like bots` |
| `{user.color}` | The chat color of the viewer | `#1E90FF` |
| `{user.display}` | The display name of the viewer who triggered this | `ViewerOne` |
| `{user.id}` | The triggering user platform ID | `123456789` |
| `{user.link}` | A profile link for the triggering user | `twitch.tv/example_viewer` |
| `{user.login}` | The login name of the viewer who triggered this | `viewerone` |
| `{user.mention}` | The viewer who triggered this, as an @mention | `@ViewerOne` |
| `{user.name}` | The login name of the person who used the command, in lower case | `example_viewer` |
| `{user.platform}` | The platform the viewer is on, in lower case | `twitch` |
| `{user.platform.name}` | The platform the viewer is on, as a name | `Twitch` |

| `{viewer.name}` | The viewer's display name (engagement triggers) | `Example_Viewer` |

| --- | --- | --- |
| `{user.accountAge}` | How long ago the triggering user account was created | `3 years` |
| `{user.accountAge.days}` | How many days old the account of the viewer is | `1534` |

## Points and saved data

| Helper | What it gives | Example |
| --- | --- | --- |
| `{user.data.<key>}` | A value stored for the viewer, with an optional default after a colon | `{user.data.color}` gives `blue` |
| `{user.points}` | The channel points of the viewer, with a thousands separator | `2,500` |
| `{user.points.name}` | The name of the points currency of the channel | `nomz` |
| `{user.points.nextRank.gap}` | How many points the viewer needs to pass the next place | `300` |
| `{user.points.nextRank.name}` | The viewer one place above on the points ranking | `ViewerThree` |
| `{user.points.rank}` | The place of the viewer on the channel points ranking | `4` |
| `{user.points.rank.ordinal}` | The place of the viewer on the points ranking as an ordinal: 4th | `4th` |
| `{user.points.raw}` | The channel points of the viewer as a plain number | `2500` |
| `{user.quotes.count}` | How many quotes the viewer said | `3` |
| `{viewer.data.<key>}` | A per-viewer data field for the triggering user (e.g. `{viewer.data.key}`) | `{viewer.data.deaths}` gives `12` |
