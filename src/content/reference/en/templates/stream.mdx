---
title: Stream helpers
description: The stream helpers for the stream right now, the last stream that ended, and the counts and top lists of a stream.
---

Helpers on this page start with `{stream.`. Type one in any reply field that takes templates, and the bot fills it in when it sends the message. A command that asks about the current game reads the live channel. A recap reads what the bot recorded about a stream. Which stream that is depends on the table the helper is in.

**Live now** reads the channel as it is at this moment. While you're offline, `{stream.uptime}` gives `offline`, `{stream.viewers}` gives `0`, `{stream.isLive}` gives `false` and `{stream.status}` gives `offline`. The other uptime, start time and viewer forms, and `{stream.id}`, give no value while you're offline.

**Counts and top lists** read the newest stream the bot has recorded for your channel. While you're live, that is the stream you're running. After you end it, it is still that stream, so a recap command keeps working until you go live again.

**The last stream** reads the newest stream that has ended. While you're live, that is the stream before this one.

The monthly counts and the category history read the newest 100 streams the bot has recorded, with the month taken in your channel time zone.

A helper with no value stays in the message as you typed it. That happens, for example, when the bot has recorded no stream yet, or when a helper that needs a number gets none. Counts use the thousands separator of your channel language, and viewers who are banned in your channel are left out of the chat, command, reward, song and event counts.

The examples show possible values; yours depend on your channel. **Use in** lists the reply fields that accept each helper. For text a viewer writes, the [Viewer Templates setting and permissions](/reference/settings/features) also apply.

## Live now

| Helper | What it gives | Example | Use in |
| --- | --- | --- | --- |
| `{stream.game}` | The current category, empty when none is set | `Just Chatting` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{stream.game.boxart}` | The box art picture link of the current category, 285 by 380 pixels | `https://static-cdn.jtvnw.net/ttv-boxart/509670-285x380.jpg` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.game.link}` | The Twitch directory link of the current category | `https://twitch.tv/directory/category/software-and-game-development` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.game.short}` | The current category, cut to 40 characters and closed with `…` | `Software and Game Development` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.id}` | The Twitch id of the running stream | `40123456789` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.isLive}` | `true` while live, `false` while offline | `true` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{stream.startedAt}` | The moment the stream went live, as a full timestamp; empty when no start time is known | `2026-10-06T18:00:00.0000000+00:00` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.startedAt.local}` | The time the stream went live, as a 24-hour clock in your channel time zone (UTC when none is set) | `13:15` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.startedAt.relative}` | How long ago the stream went live, rounded | `2 hours ago` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.status}` | `live` or `offline` | `live` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.thumbnail}` | The link to the live preview picture; empty on a platform other than Twitch | `https://static-cdn.jtvnw.net/previews-ttv/live_user_example_channel-1280x720.jpg` | Discord |
| `{stream.title}` | The current title, empty when none is set | `Cozy coding night` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{stream.title.short}` | The title cut to the number of characters you give, from 1 to 140, and closed with `…`; a title that fits stays whole | `{stream.title.short:8}` gives `Building…` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.uptime}` | How long the stream has been live; `offline` while offline | `2h 15m` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{stream.uptime.clock}` | How long the stream has been live, as a clock; under an hour it reads `15:00` | `2:15:00` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.uptime.hours}` | How many hours the stream has been live, with up to two decimals | `2.25` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.uptime.long}` | How long the stream has been live, in words, with two units at most | `2 hours, 15 minutes` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.uptime.minutes}` | How many whole minutes the stream has been live | `135` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.uptime.since}` | The time the stream went live in your channel time zone, with words before it | `live since 13:15` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.url}` | The link to your channel page on Twitch or Kick | `https://www.twitch.tv/example_channel` | Discord |
| `{stream.viewers}` | The current viewer count; `0` while offline | `42` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.viewers.compact}` | The current viewer count, short from 1,000 up: 1,234 reads `1.2k` and 3,400,000 reads `3.4M`; below 1,000 the count stays whole | `1.2k` | Commands, event responses, timers, pipelines, Discord, webhooks |

`{stream.thumbnail}` and `{stream.url}` work only in a Discord notification, which fills them in itself when it sends the post. In any other field they stay as typed.

## Counts and top lists

These read the newest recorded stream: the running one while you're live, the one you ended last while you're offline. A list of viewer names, such as the top chatters or the new followers, holds at most five.

| --- | --- | --- | --- |

| `{stream.bits.total}` | All bits cheered | `1,250` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.chatters.unique}` | How many different viewers chatted | `33` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.commandsRun}` | How many times a command ran | `88` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.count}` | How many streams the bot has recorded for your channel | `214` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.count.month}` | How many recorded streams started this month | `11` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.followers.new}` | How many follows came in | `6` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.followers.newList}` | The names of the first five people who followed, in the order they followed | `ViewerOne, ViewerTwo` | Commands, event responses, timers, pipelines, Discord, webhooks |

With no number it stays as typed | `{stream.topChatters:3}` gives `ViewerOne, ViewerTwo, ViewerThree` | Commands, event responses, timers, pipelines, Discord, webhooks |

`{stream.count}`, `{stream.count.month}`, `{stream.hours.month}` and `{stream.games.history}` look across your recorded streams, not only the newest one.

## The last stream

These read the newest stream that has ended. While you're live, that is the stream before this one.

| Helper | What it gives | Example | Use in |
| --- | --- | --- | --- |
| `{stream.last.duration}` | How long it lasted | `4h 10m` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.endedAt}` | The date it ended, in UTC | `2026-10-24` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.followers}` | How many people followed during it | `9` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.game}` | Its category | `Just Chatting` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.messages}` | How many chat messages it had | `3,102` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.peak}` | Its highest viewer count | `61` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.relative}` | How long ago it ended, rounded | `2 days ago` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.since}` | How long ago it ended, in words, with two units at most | `1 day, 16 hours` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.subs}` | How many people subscribed during it | `4` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{stream.last.title}` | Its title | `Chill Saturday` | Commands, event responses, timers, pipelines, Discord, webhooks |

For a recap you post while live, use these. For one you post right after you end the stream, the count helpers above already describe that stream and carry more detail.
