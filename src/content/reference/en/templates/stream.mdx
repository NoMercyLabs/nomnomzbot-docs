Helpers on this page: `{stream.*}`.

These helpers describe the stream right now, the last stream, and the counts of a stream.
Use them in an uptime command, a "what are we playing" command, or an end-of-stream recap.
A row marked "Discord seed alias" works only in a Discord notification, which fills in the value itself when it sends the message. In a command or an event response it stays as typed.

Each row is its own example, so the rows on this page do not all come from one moment.

## Live now

| Helper | What it gives | Example |
| --- | --- | --- |
| `{stream.game}` | The stream current game/category | `Just Chatting` |
| `{stream.game.boxart}` | The box art picture link of the current category | `https://static-cdn.jtvnw.net/ttv-boxart/509670-285x380.jpg` |
| `{stream.game.link}` | The Twitch directory link of the current category | `https://twitch.tv/directory/category/software-and-game-development` |
| `{stream.game.short}` | The category name, cut to 40 characters | `Software and Game Development` |
| `{stream.id}` | The Twitch id of the running stream | `40123456789` |
| `{stream.isLive}` | Whether the stream is currently live | `true` |
| `{stream.startedAt}` | The timestamp the stream went live | `2026-10-06T18:00:00.0000000+00:00` |
| `{stream.startedAt.local}` | The time the stream went live, in the channel time zone | `13:15` |
| `{stream.startedAt.relative}` | How long ago the stream went live: 2 hours ago | `2 hours ago` |
| `{stream.status}` | live or offline | `live` |
| `{stream.thumbnail}` | The link to the live stream preview picture, empty when the platform has none (Discord seed alias) | `https://static-cdn.jtvnw.net/previews-ttv/live_user_example_channel-1280x720.jpg` |
| `{stream.title}` | The stream current title | `Cozy coding night` |
| `{stream.title.short}` | The stream title cut to a number of characters, closed with an ellipsis | `{stream.title.short:8}` gives `Building…` |
| `{stream.uptime}` | How long the stream has been live | `2h 15m` |
| `{stream.uptime.clock}` | How long the stream has been live as a clock: 2:15:00 | `2:15:00` |
| `{stream.uptime.hours}` | How many hours the stream has been live, with decimals | `2.25` |
| `{stream.uptime.long}` | How long the stream has been live, in words: 2 hours, 15 minutes | `2 hours, 15 minutes` |
| `{stream.uptime.minutes}` | How many minutes the stream has been live | `135` |
| `{stream.uptime.since}` | The time the stream went live in the channel time zone: live since 13:15 | `live since 13:15` |
| `{stream.url}` | The link to the live stream on its platform (Discord seed alias) | `https://www.twitch.tv/example_channel` |
| `{stream.viewers}` | The current viewer count | `42` |
| `{stream.viewers.compact}` | The current viewer count, short: 1.2k | `42` |
| `{stream.viewers.peak}` | The highest viewer count of this stream | `57` |

| `{stream.last.followers}` | How many people followed during the last finished stream | `9` |
| `{stream.last.game}` | The category of the last finished stream | `Just Chatting` |
| `{stream.last.messages}` | How many chat messages the last finished stream had | `3,102` |
| `{stream.last.peak}` | The highest viewer count of the last finished stream | `61` |
| `{stream.last.relative}` | How long ago the last finished stream ended, rounded: 2 days ago | `2 days ago` |
| `{stream.last.since}` | How long ago the last finished stream ended, in words | `1 day, 16 hours` |
