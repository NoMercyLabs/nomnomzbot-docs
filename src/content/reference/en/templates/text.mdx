Helpers on this page: `{text.*}`.

These helpers change a text: letter case, style, words, length, replacing, encoding and plurals.
Put the input after a colon, as in `{text.upper:hello}`.
Separate more than one input with a pipe.
Most helpers take the text first.
Some take a number first, as in `{text.first:3|hello}`, so follow the order in each example.
A text input keeps its spaces exactly as you type them.
An input that is a number or a setting ignores the spaces around it.
To write a space on purpose, you can also type a backslash and s.

## Start with a small transformation

Text helpers change the value you give them before it appears in the reply.
`{text.upper:hello chat}` gives `HELLO CHAT`; `{text.upper:{args}}` applies the same operation to the words after a command.
The nested helper supplies the input, so you can change the presentation without asking viewers to type capitals themselves.

For a short display, `{text.cut:hello world|max=8|end=...}` gives `hello...`.
The maximum includes the ending, so the final text fits in eight characters.
The table distinguishes this from helpers that append an ellipsis after taking a specified number of characters or words.

The examples illustrate possible values; your results depend on the channel and trigger.
**Use in** lists the template fields that accept each helper.
A pipeline still needs a trigger that supplies the relevant person, message, or event; event-specific helpers need that event.
For viewer-written text, the [Viewer Templates setting and permissions](/reference/settings/features) also apply.

## When a helper cannot use its input

A helper that cannot use its input stays in the reply as written.
These inputs cause it:

- The wrong number of inputs.
- A count, width or length that is not a whole number from 0 to 1000, in every helper that takes one. The plural helpers are the exception: `{text.plural}`, `{text.plural.count}` and `{text.plural.auto}` take any whole number, negative ones too.
- A position below 1. Positions count from 1, and a position past the end gives empty text.
- An empty text to find, in `{text.count}`, `{text.remove}`, `{text.replace}` and `{text.censor}`.

`{text.count}`, `{text.remove}` and `{text.replace}` match letter case exactly.
`{text.censor}` and `{text.replace.icase}` ignore letter case.
In a viewer's own text, a repeat count and a pad or center width above 20 are cut to 20, so `{text.repeat:30|ha}` gives 20 copies.
