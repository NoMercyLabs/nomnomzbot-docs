Helpers on this page: `{random.*}`, `{pick}`, `{pick.*}`, `{chance*}`, `{roll.*}`.

These helpers pick a random value, number, item or roll.
Each evaluation makes a random draw, so the example shows one possible result and results can repeat.
Use them for a playful random answer; use the giveaway feature for managed entries and recorded winners.

## Decide whether each mention should draw again

Use `{pick:Pizza|Pasta|Soup}` when you want one suggestion from a short set written directly in the reply.
For a set you want to manage separately or share across commands, use a [pick list](/reference/commands/pick-lists).
Random draws can repeat; they are not a way to guarantee that every choice appears before another is picked.

When the same number needs to appear twice, give it a roll name.
`{roll.score.1.100} out of 100; score again: {roll.score}` draws the number once for that reply and reuses it, so both places agree.
Ordinary random helpers draw independently.

In an authored reply, `{pick:Pizza|Pasta|Soup}` avoids selecting the same entry immediately twice when there is more than one choice.
That short-term memory ends when the bot restarts, and viewer-written `{pick:...}` uses ordinary random selection instead.
A single available choice can always repeat.

A random-chatter helper is a playful choice from the chatters it can see.
Use [Giveaways](/reference/economy/giveaways) when you need entry rules, a recorded winner, and a claim process.

The examples illustrate possible values; your results depend on the channel and trigger.
**Use in** lists the template fields that accept each helper.
A pipeline still needs a trigger that supplies the relevant person, message, or event; event-specific helpers need that event.
For viewer-written text, the [Viewer Templates setting and permissions](/reference/settings/features) also apply.

| Helper | What it gives | Example | Use in |
| --- | --- | --- | --- |
| `{chance}` | Shows the first text with the given chance in percent, else the second: `{chance:10\|then\|else}` | `{chance:100\| sure \|never}` gives `sure` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{pick}` | Picks one of the texts at random: `{pick:a\|b\|c}`. Authored replies avoid an immediate repeat; viewer-written text can repeat | `{pick: a }` gives `a` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{pick.inline}` | Picks one item of a list written with semicolons, so an item may hold a pipe: `{pick.inline:a;b;c}` | `{pick.inline: a ; a }` gives `a` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{pick.n}` | Picks a number of different texts at random: `{pick.n:2\|a\|b\|c}` | `{pick.n: 1 \| a }` gives `a` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{pick.shuffle}` | Lists all texts in a random order: `{pick.shuffle:a\|b\|c}` | `c, a, b` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{pick.weighted}` | Picks one text at random, a bigger weight is more likely: `{pick.weighted:1=rare\|9=common}` | `{pick.weighted: 1 = a }` gives `a` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{random.bool}` | Randomly true or false, for use inside `{if:...}` | `true` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{random.chatter}` | A random viewer who has chatted this stream: `{random.chatter}` | `ViewerOne` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{random.chatter.mention}` | A random chatter this stream with an @ in front, so they get a mention: `{random.chatter.mention}` | `@ViewerOne` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{random.chatter.notMe}` | A random chatter this stream, never the viewer who triggered it: `{random.chatter.notMe}` | `ViewerTwo` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{random.color}` | A random color as a hex code, such as #3FA7D6 | `#3FA7D6` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{random.decimal}` | A random number with decimals: `{random.decimal:min\|max\|places}` | `{random.decimal: 1 \| 1 \| 2 }` gives `1.00` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{random.letter}` | A random letter from A to Z | `K` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{random.number}` | A random whole number: `{random.number:6}` is 1 to 6, `{random.number:10\|50\|10}` is 10, 20 up to 50 | `{random.number: 5 \| 5 }` gives `5` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{random.number.<min>.<max>[.<step>]}` | A random whole number between a minimum and a maximum, with an optional step (e.g. `{random.number.50.990.10}`) | `{random.number.50.990.10}` gives `430` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{random.number.<n>}` | A random whole number from 1 up to N (e.g. `{random.number.100}`) | `{random.number.1}` gives `1` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{random.percent}` | A random percent from 0% to 100% | `37%` | Commands, event responses, timers, pipelines, Discord, webhooks, viewer text |
| `{random.pick.<a.b.c>}` | A random pick from a dot-separated list (e.g. `{random.pick.a.b.c}`) | `{random.pick.red.green.blue}` gives `green` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{random.quote}` | A random quote of the channel with its number, author and date: `{random.quote}` | `#12 "that was close" (ViewerTwo, 2026-03-01)` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{random.user}` | A random chatter currently in the channel | `example_viewer` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{roll.<name>}` | The value of a named roll again, so one roll can show in many places (e.g. `{roll.pct}`) | `{roll.pct.60.98} and {roll.pct}` gives `73 and 73` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{roll.<name>.<min>.<max>[.<step>]}` | A named random roll, drawn once per message: name, minimum, maximum and an optional step (e.g. `{roll.pct.60.98}`) | `{roll.pct.60.98}` gives `73` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{roll.<name>.complement}` | 100 minus a named roll, for two percentages that add up to 100 (e.g. `{roll.pct.complement}`) | `{roll.pct.60.98} and {roll.pct.complement}` gives `73 and 27` | Commands, event responses, timers, pipelines, Discord, webhooks |
