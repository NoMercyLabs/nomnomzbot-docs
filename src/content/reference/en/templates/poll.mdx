Helpers on this page: `{poll.*}`, `{prediction.*}`.

These helpers read the current or last poll and prediction.
Use them to announce a result in chat, on an overlay or read aloud.

The examples illustrate possible values; your results depend on the channel and trigger.
**Use in** lists the template fields that accept each helper.
A pipeline still needs a trigger that supplies the relevant person, message, or event; event-specific helpers need that event.
For viewer-written text, the [Viewer Templates setting and permissions](/reference/settings/features) also apply.

| `{poll.last.question}` | The question of the last poll that finished | `Best snack?` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{poll.last.winner}` | The winning option of the last poll that finished | `chips` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{poll.leading}` | The option with the most votes; empty before the first vote | `chips` | Commands, event responses, timers, pipelines, Discord, webhooks |

| `{poll.timeLeft}` | How long the running poll has left: 1m 30s | `1m 30s` | Commands, event responses, timers, pipelines, Discord, webhooks |
