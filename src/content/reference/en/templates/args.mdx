Helpers on this page: `{args}`, `{args.*}`.

These helpers read the words a viewer typed after the command, such as the first word or the second word.
Use them to take a word, a number or a duration from the command.
They can also read a person from a word, such as `{args.1.user.points}`, and give facts about that person.

Each row is its own example, so the rows on this page do not all come from one moment.

## Words after the command

| Helper | What it gives | Example |
| --- | --- | --- |
| `{args}` | Everything typed after the command, as one text | `hello world` |
| `{args.<a>-<b>}` | The words from the a-th to the b-th, for example args.2-3 | `{args.2-3}` gives `hello big` |
| `{args.<n>}` | Command argument N (e.g. `{args.1}` is the first word after the command) | `{args.1}` gives `@ViewerTwo` |
| `{args.<n>+}` | Every word from the n-th one to the end, for example args.2+ | `{args.2+}` gives `hello big world` |
| `{args.<n>.clean}` | The n-th word without a leading @ | `{args.1.clean}` gives `ViewerTwo` |
| `{args.<n>.isMention}` | True when the n-th word is an @mention | `{args.1.isMention}` gives `true` |
| `{args.<n>.isNumber}` | True when the n-th word is a number | `{args.1.isNumber}` gives `false` |
| `{args.<n>.length}` | How many characters the n-th word has | `{args.2.length}` gives `5` |
| `{args.<n>.number}` | The n-th word when it is a number, else the default after the colon or nothing | `{args.3.number:1}` gives `1` |
| `{args.<n>.upper}` | The n-th word in UPPERCASE | `{args.2.upper}` gives `HELLO` |
| `{args.<n>.urlEncoded}` | The n-th word made safe for a web address | `{args.2.urlEncoded}` gives `hello` |
| `{args.<n>:<default>}` | The n-th word, or the default after the colon when the command has fewer words | `{args.5:nobody}` gives `nobody` |
| `{args.all.quoted}` | All arguments in double quotes | `{args.all.quoted}` gives `"@ViewerTwo hello big world"` |
| `{args.all.urlEncoded}` | All arguments made safe for a web address | `{args.all.urlEncoded}` gives `%40ViewerTwo%20hello%20big%20world` |
| `{args.count}` | How many words follow the command | `{args.count}` gives `4` |
| `{args.duration}` | Reads the word at a position as a time (5m, 1h30m, 90) and gives it in seconds. Type the position after a colon: when the second word is 5m, 2 gives 300 | `{args.duration:2}` gives `300` |
| `{args.first}` | The first word after the command, as written | `{args.first}` gives `@ViewerTwo` |
| `{args.isEmpty}` | True when the command has no arguments, false when it has some | `{args.isEmpty}` gives `false` |
| `{args.last}` | The last word after the command | `{args.last}` gives `world` |
| `{args.mentions}` | Every @mention in the arguments | `{args.mentions}` gives `@ViewerTwo` |
| `{args.mentions.count}` | How many @mentions are in the arguments | `{args.mentions.count}` gives `1` |
| `{args.numbers}` | Every word that is a number | `{args.numbers}` gives `42 7` |
| `{args.rest}` | Every word after the first one | `{args.rest}` gives `hello big world` |
