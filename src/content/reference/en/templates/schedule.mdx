Helpers on this page: `{schedule.*}`.

These helpers read the channel's stream schedule.
Use them to tell viewers when the next stream starts.

The examples illustrate possible values; your results depend on the channel and trigger.
**Use in** lists the template fields that accept each helper.
A pipeline still needs a trigger that supplies the relevant person, message, or event; event-specific helpers need that event.
For viewer-written text, the [Viewer Templates setting and permissions](/reference/settings/features) also apply.

| Helper | What it gives | Example | Use in |
| --- | --- | --- | --- |
| `{schedule.ical}` | The link to the channel schedule as a calendar file (iCalendar) | `https://api.twitch.tv/helix/schedule/icalendar?broadcaster_id=123456` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.link}` | The link to the channel schedule page | `https://twitch.tv/samplechannel/schedule` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.list}` | The next scheduled streams with their start times, for example schedule.list:3: Fri 20:00 Bot night · Sun 14:00 Chill | `{schedule.list:3}` gives `Fri 20:00 Bot night · Sun 14:00 Chill · Tue 20:00 Bot night` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.at}` | The day and start time of the next scheduled stream: Friday 20:00 | `Friday 20:00` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.date}` | The day and date of the next scheduled stream: Friday 30 October | `Friday 30 October` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.duration}` | How long the next scheduled stream lasts: 3h | `3h` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.full}` | The next scheduled stream in one line: next stream in 4 days, Friday 20:00 | `next stream in 4 days, Friday 20:00` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.game}` | The category of the next scheduled stream | `Software and Game Development` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.in}` | How long until the next scheduled stream: 4 days | `4 days` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.isRecurring}` | true when the next scheduled stream repeats every week, false when it is a one-off | `true` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.relative}` | How long until the next scheduled stream, as a phrase: in 4 days | `in 4 days` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.title}` | The title of the next scheduled stream | `Bot night` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.next.viewerTime}` | The day and start time of the next scheduled stream in another time zone, for example schedule.next.viewerTime:America/New_York: Fri 15:00 | `{schedule.next.viewerTime:America/New_York}` gives `Fri 15:00` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.today}` | The scheduled streams of today with their start times; empty when there is none: 21:00 Quick one | `20:00 Bot night` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.vacation}` | The schedule break that is planned or running; empty when there is none: Fri 6 Nov - Sun 15 Nov | `Fri 6 Nov - Sun 15 Nov` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.vacation.until}` | The day the schedule break ends; empty when there is no break: Sunday 15 November | `Sunday 15 November` | Commands, event responses, timers, pipelines, Discord, webhooks |
| `{schedule.week}` | The days this week (Monday to Sunday) with a scheduled stream: Fri, Sun | `Fri, Sun` | Commands, event responses, timers, pipelines, Discord, webhooks |
