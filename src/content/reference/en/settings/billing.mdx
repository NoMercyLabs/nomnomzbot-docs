You read the channel's account details on the **Billing** page.
It sits in the **Account** group of the settings sidebar.
The limits and usage of a plan are on [Resource limits](/reference/settings/resource-limits).

::Callout

Running it for yourself, your friends and your community is free. You may not earn money with it: no selling it, and no paid hosting or paid service built on it.

::

The plain rule about use is on the [overview](/reference/overview).
The page shows the same rule at the bottom of **Your plan**.

## Who can use this page

Only the **Broadcaster** may open the page and change the plan.
Moderators and editors do not see billing.

## What the page holds

| Panel | What it holds |
| --- | --- |
| **Your plan** | The plan this channel is on, its state and its dates. |
| **Plans** | The plans on offer, with their price and what each includes. |
| **Invite code** | A field for a code that can unlock a plan or the founders badge. |
| **Invoices** | What you were billed and what you paid, newest first. |

## Read your plan

**Your plan** shows the plan name and a state badge.

| State | Meaning |
| --- | --- |
| **Active** | The plan runs. |
| **Trial** | The plan runs as a trial. |
| **Payment overdue** | A payment is late. |
| **Canceled** | The plan has ended. |
| **Not finished** | The plan was not set up to the end. |

Under the name, the panel lists the dates that apply: **Renews on**, **Ends on**, **Trial ends on** or **Pay before**.
It also shows **Custom bot name** and **Priority support**, each **Included** or **Not included**.

A plan from an invite code shows "This plan came from an invite code. It has no payment to manage."
That plan has no payment buttons.

## Compare and choose a plan

**Plans** lists each plan with its price, **Free** or a price per month.
Your own plan shows **Current plan**.

| Row | What it shows |
| --- | --- |
| **Sound clip storage** | How much sound clip space the plan gives. |
| **Channel asset storage** | How much space for channel files the plan gives. |
| **Script run time per month** | How long code scripts may run each month. |
| **Text-to-speech message length** | How many characters one text to speech message may have. |
| **Custom bot name** | **Included** or **Not included**. |
| **Priority support** | **Included** or **Not included**. |

A limit row shows only when at least one plan sets it.
A cell reads **No limit** when the plan has no cap, and **Not included** when the plan does not have it.

1. Without a paid plan, choose **Choose plan** under a paid plan.
   The payment page opens.
2. With a paid plan, choose **Switch to this plan** under another plan.
   The plan changes in place.

With a paid plan, the panel also shows **Switch at the end of the period**.
Default: on.
Off: the new plan starts now.

## Manage payment or cancel

These buttons sit at the bottom of **Your plan**, for a paid plan only.

- **Manage payment** opens the payment page.
- **Cancel plan** opens the "Cancel your plan?" dialog.
- **Keep my plan** shows when the plan is set to end, and keeps it.

The cancel dialog lists what happens: "Limits drop to the free plan.", "Paid features turn off." and "Your data stays."

1. Leave **Cancel right away** off to keep the plan until the end of the period you paid for.
   Switch it on to end the plan now.
2. Type a reason in **Why are you leaving? (optional)**, or leave it empty.
3. Choose **Cancel plan**.
   With **Cancel right away** off, the panel shows "This plan is set to end. You keep it until the date above."

## Use an invite code

1. Type the code in **Code**.
2. Choose **Check code** to look at it without using it up.
   The panel shows "This code is valid." or "This code is not valid.", what it unlocks, the uses left and the last valid date.
3. Choose **Use code** to redeem it.
   The panel shows "The code is used." and the plan or badge it gave.

Below the field, **Founders badge** shows whether the channel has the badge, since when, and from which code.

## Read your invoices

**Invoices** lists each invoice with its number, amount and status.
Each line shows when it was issued, due, paid or refunded.
**Open invoice** opens the invoice page in a new tab, when the invoice has one.
Use **Previous page** and **Next page** to move through older invoices.

When there are none, the panel shows "No invoices yet."
