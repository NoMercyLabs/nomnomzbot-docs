This page lists the widget SDK, the events a widget can receive, the parameters of every pipeline action and the calls that render a template.
A widget uses the `NomNomz` name, and a script uses `nnz`.
[Script basics](/reference/code/sdk-script-basics) explains the grants, the error codes and the `nnz.lastError` value of a script.

## Before you start

Custom Code is off for a new channel.
A script call on this page works only when Custom Code is on.
[Script basics](/reference/code/sdk-script-basics) shows how to switch it on.

You add and set up a widget on [Widgets and alerts](/reference/overlays/widgets-and-alerts).

## The widget SDK

The SDK is the `NomNomz` name in the widget page.
It is loaded before the widget code runs.
Each call that registers a handler gives back `NomNomz`, so calls chain.

| Member | What it does |
| --- | --- |
| `NomNomz.on(eventType, handler)` | Calls `handler(data, eventType, meta)` for each event of that name. |
| `NomNomz.off(eventType, handler)` | Removes a handler. Pass the same function you gave to `on`. |
| `NomNomz.onAny(handler)` | Calls `handler(eventType, data, meta)` for every event. |
| `NomNomz.onSettings(handler)` | Calls `handler(settings)` at once, then again on every change in the dashboard. |
| `NomNomz.settings` | The widget's settings now. |
| `NomNomz.widget.id` | The id of this widget. |
| `NomNomz.widget.name` | The name of this widget. |
| `NomNomz.reportError(message)` | Logs the message and reports it to the bot as a widget error. |
| `NomNomz.actions.invoke(actionType, params, variables)` | Runs one pipeline action. |
| `NomNomz.actions.claim(key)` | Claims an event for this one copy of the widget. |
| `NomNomz.data.nowPlaying()` | The track that plays now, or `null`. |
| `NomNomz.data.queue()` | The music queue, without the track that plays now. |
| `NomNomz.data.storage(key)` | One value from the channel's script storage, or `null`. |
| `NomNomz.data.streamStats(options)` | Metrics of one stream. |
| `NomNomz.template.render(template, values)` | The template as text for this channel. |
| `NomNomz.spotify.playbackToken()` | A short-lived Spotify token for the Spotify player. |
| `NomNomz.reportYouTubePlayerState(videoId, state, positionMs)` | Tells the bot what a YouTube player page plays. |
| `NomNomz.reportMediaSharePlayerState(requestId, state, positionSeconds, durationSeconds, volume)` | Tells the bot what the media-share player does. |

The widget gets only the events it registered with `on`.
`onAny` registers every event.

### Live events and replays

The `meta` value says where an event comes from.

| Field | Meaning |
| --- | --- |
| `replay` | `true` for a remembered event the bot sends again when the widget joins. `false` for a live event. |
| `occurredAt` | The time the replayed event really happened. Only set when `replay` is `true`. |
| `test` | `true` for a test fire from the dashboard. Show it, but do not keep it as the widget's value or count. |

A handler that you register late still gets the remembered events it would have seen.

### Claim an event

`NomNomz.actions.claim(key)` gives `true` only for the first open copy of the widget that claims the key.
Every other copy gets `false`.
A claim holds for ten minutes.

Claim an event, for example with its redemption id, before you act on it.
Then two OBS sources never both act on one event.

The claim fails with an error when the widget is not connected to the bot, or the key is empty or over 200 characters.
Catch that error.

### Read the channel's state

The `NomNomz.data` calls fail with an error when the request fails.
`streamStats` takes `stream` and `metrics`.
Leave out `stream` for the latest stream, live or ended.

`NomNomz.spotify.playbackToken()` never fails with an error.
It gives `{ error: 'blocked' }` when the bot may not play here, and `{ error: 'error' }` when the request failed.
Ask again each time the Spotify player wants a token.

This widget shows each new follower with a line from a template:

```js
NomNomz.on('follow', async (data, eventType, meta) => {
  if (meta?.test) return;

  const line = await NomNomz.template.render('Welcome {name}!', { name: data.displayName });

  document.querySelector('#line').textContent = line;
});
```

## Run a pipeline action

A pipeline action is one step of a pipeline.
A widget and a script can run any action type in the table below.
A pipeline runs the same action types as steps.

### From a widget

`NomNomz.actions.invoke(actionType, params, variables)` runs one action as the channel owner, within the owner's own permissions.
`params` holds the action's parameters, and `variables` holds values the action can read.
You can leave out `params` when the action has no required parameter.

The call gives back a result, also when the bot refuses the action or the action fails.
It fails with an error only when the widget is not connected to the bot.

| Field | Meaning |
| --- | --- |
| `success` | `true` when the action ran and succeeded. |
| `output` | The text the action gave back, or `null`. |
| `error` | Why it failed, or `null`. |
| `errorCode` | Set when the bot refused to run it. |
| `variables` | The action's values after the run, for example `tts.audioUrl` and `tts.durationMs`. |

| Refusal code | Meaning |
| --- | --- |
| `AUTH_REQUIRED` | The widget connection is not signed in. |
| `FORBIDDEN` | The widget belongs to another channel, or the widget is turned off. |
| `NOT_FOUND` | Nothing matches. |
| `VALIDATION_FAILED` | A value is missing or wrong. |
| `RATE_LIMITED` | Too many calls. |

Treat a code that is not in this table as a refusal too.

### From a script

`nnz.api.actions.invoke('type', params, variables)` runs one action from a script.
Its grant is `actions.invoke:` and the type, so the type must be text in quotes.
It gives back `success`, `output`, `error` and `variables`.

When the action fails, the script goes on, and `nnz.lastError` says why.
`params` and `variables` must each be an object.

```js
const result = nnz.api.actions.invoke('tts_synthesize', { text: 'Thanks for the raid!' });

if (!result.success) {
  nnz.api.chat.send('No voice line: ' + nnz.lastError.message);
}
```

The bot posts that line in chat in the channel's one bot voice.

## Send a widget an event from a script

`nnz.api.widget.emit(widgetIdOrName, eventType, data)` sends an event to one widget of the channel.
The widget gets it in its `NomNomz.on(eventType, ...)` handler.
`data` is optional and is sent as the event's payload.

It gives `true` when the event is sent, and `false` when it is not.
Then `nnz.lastError` says why.

| Code | When |
| --- | --- |
| `invalid_argument` | The widget or the event name is empty, or `data` is not valid JSON. |
| `not_found` | No widget of this channel matches. |
| `refused` | The widget is turned off, or it is open in no browser source. |
| `upstream_failed` | The event could not be sent to the overlay. |

```js
const sent = nnz.api.widget.emit('Alerts', 'hug', { from: bot.args[0] || 'chat' });

if (!sent) {
  nnz.api.chat.send('The widget did not get it: ' + nnz.lastError.message);
}
```

## Render a template

A template is text with helpers in braces, such as `{name}` or `{name:argument}`.
[Variables and templates](/reference/commands/variables-and-templates) lists every helper and what it gives.
The bot renders the template for this channel.

| Call | Gives |
| --- | --- |
| `NomNomz.template.render(template, values)` | A promise of the text. |
| `nnz.template.render(template, values)` | The text. |

`values` fills the plain names of the template.
Each value must be text, a number, or `true` or `false`.

A template can be at most 4096 characters.
An empty template or a longer one is refused.
In a widget the promise fails with an error, and in a script the call gives empty text and `nnz.lastError` says why.
