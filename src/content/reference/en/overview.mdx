NomNomzBot is a chat bot for your stream.
This guide shows you how to set it up and run it for your channel.

## What NomNomzBot is

You set up the bot in the [dashboard](/reference/getting-started/sign-in).
The dashboard is a website.

The bot answers in chat in the channel's one [bot voice](/reference/getting-started/bot-account).
It speaks aloud only through [text to speech](/reference/audio/text-to-speech).

## Who this guide is for

This guide is for streamers and their moderators.
You do not need to write code to use it.

The last part of the guide, **Code and SDK (Draft)**, is for readers who write a little code.

The **Draft** label on that part means the part is not finished yet.
The part describes only what the bot can do today.

## The rule about use

::Callout

NomNomzBot is free to use, change and share. You may not earn money with it.

::
