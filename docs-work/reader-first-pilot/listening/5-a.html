First-run setup

A new self-hosted bot opens a setup page so it can learn which applications to use when talking to Twitch and other services. These application details identify the bot to a service; approving an account connection later gives it permission to act for that account. You can complete the required Twitch step first and leave the optional services until you need them.

You reach this page after you install with Docker and open the bot in your browser. Docker must be running and the bot’s address reachable. You do not need an existing bot login, a separate bot account, optional service apps, text-to-speech setup or a working event feed for the required setup.

The steps

The page shows the steps in a row at the top, with the current step marked. On a narrow screen, the row shows “Step 1 of 6” and the name of the current step.

Under each card, Back goes to the step before. On a needed step, Next stays off until the step is done. On an optional step that is not done, the button reads Skip.

Finish the setup soon after you start the bot. Until you choose Finish setup, anyone who can open the bot’s address can change the keys on this page. After that, only an admin of the bot can change them; being a channel moderator is not enough.

1. Choose the Twitch app

The bot talks to Twitch through a Twitch app. You can register your own app, or use the shared NomNomzBot app. Your own app is encouraged.

Registering an application does not mean writing code. You create a record in Twitch’s Developer Console and copy its Client ID into the bot. Twitch requires a verified email address and two-factor authentication before you register an application.

To use your own app:

  1. Open the Twitch Developer Console from the link on the card, and register a new application.
  2. Set the OAuth Redirect URL to the address the card shows. Use the copy button beside the address, so the address matches exactly.
  3. Choose the “Chat Bot” category, create the app, and copy the Client ID.
  4. Paste it into Client ID and choose Save. The step is now done, and Next turns on.

Client Secret (optional) can stay empty. Without it, you sign in with a code. With it, you can also sign in with one tap.

OAuth is the sign-in process that asks you to approve permissions on the service’s own website. The redirect or callback address is where that website sends your browser afterward, so copy it exactly from the setup card. Keep the client secret private, just as you would a password.

To use the shared app instead, choose Use the shared NomNomzBot app. You fill in no fields, and the step is done.

Only a saved Client ID or a click on the shared app finishes this step.

2. Add a bot account

This step is optional. Skip it, and the broadcaster account types in chat as the bot. The bot account page explains which account the bot types from.

To add a separate bot account:

  1. Sign in to Twitch as the bot’s own account in this browser first.
  2. Choose Authorize the bot account. Twitch opens in a new tab, and the card shows “Waiting for you to approve the account on Twitch…”.
  3. Approve the chat permissions that Twitch asks for. The card shows “Connected:” and the name of the account, and the step is done.

While the card waits, it also shows the link to Twitch with a copy button. Use it when the bot account is signed in to another browser or profile.

3. Add Spotify, Discord or YouTube

These three steps are optional. Each one asks for a Client ID and a Client Secret from an app that you make at that service. The card links to the place where you make the app.

StepWhat it turns onWhere you add the address the card shows
SpotifySpotify account connection and music features; not a requirement for all song requestsThe Redirect URI of a Spotify app
DiscordNotifications and server syncThe OAuth2 Redirect of a Discord application
YouTubeGoogle sign-in for the channel’s YouTube account connectionThe Authorized redirect URI of a Google OAuth credential
  1. Make the app at the service, and add the address that the card shows. Use the copy button beside the address.
  2. Copy the Client ID and the Client Secret into the two fields.
  3. Choose Save. The step is done.

You can also leave these out now.

Saving application credentials prepares the service connection; it does not select your Spotify playback device or finish linking an individual account. YouTube song requests do not require this Google app or a YouTube account connection: music search and playback use a separate public/keyless path. The setup page’s description of a “YouTube music provider” should not be read as a prerequisite for requesting YouTube music. After signing in, follow the guides for Spotify, Discord or YouTube for the feature you want to use.

4. Finish setup

The last card lists every step with Done or Not set. Below the list is the Event feed check. On a new bot it says “Sign in after you finish setup. Then this page can check that Twitch events reach the bot.”

Choose Finish setup. The bot opens the dashboard, and you sign in.

Sign in as the broadcaster to connect your channel, then try your first command. The optional Event feed check on the finish screen is not a prerequisite for that first sign-in: a new bot has no broadcaster connection to check yet.

Troubleshooting

When something is not right

The page says “This bot does not answer. Check that it runs, then try again.” The browser cannot reach the bot. In a terminal in the project folder, run the command for your setup:

docker compose -f docker-compose.lite.yml ps

For the full setup, run docker compose ps. The bot’s row must show Up and healthy. If it does not, start the bot again with the command from Install with Docker, then choose Try again.

When something is not right

Next stays off on the Twitch app step. A Client ID that the bot already knows does not count. Choose Save with your own Client ID, or choose Use the shared NomNomzBot app.

When something is not right

Saving shows “The bot could not save this. Check the values and try again.” Check the values you pasted. If the setup is already finished, only an admin of the bot can save new keys.

When something is not right

Finish shows “The bot could not finish setup. Try again.” Choose Finish setup again. If the setup was already finished from another browser, only an admin of the bot can finish it again.
