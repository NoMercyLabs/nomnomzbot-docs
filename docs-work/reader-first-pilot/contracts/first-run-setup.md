## Reader, task and prerequisites

Reader: self-hosting streamer with an installed bot who is unfamiliar with application credentials/OAuth. Main question: “What must I configure before first sign-in, what can wait, and how do I finish safely?” Success: explicitly choose/save a Twitch app, skip unneeded optional services, finish setup, then sign in as broadcaster and connect channel.

Prerequisites: Docker installation from linked guide is running and bot URL reachable in browser. No existing bot login, separate bot account, Spotify/Discord/Google app, TTS or event-feed connection is required for minimal setup. For an own Twitch app, access to the Twitch Developer Console with verified email and 2FA, and the exact callback address shown by this instance; Client ID required, Client Secret optional. Shared app path requires neither own app fields nor secret. Optional services require their respective app credentials; account linking follows later. After setup is explicitly finished, credential changes require bot administrator access (not merely a channel moderator).
