# Calibration protocol

Both runs use fresh reader contexts, with one variant per topic in each context. A reader never receives a paired alternative, source/card rationale, answer key or diagnostics before saving six answers/findings. Every initial record is preserved. Citation-only repairs precede diagnostics and preserve answer/findings text. Length warnings are released afterward by the checker; final verdicts are separate.

## Run 1

Readers first read the whole rendered article, then answered four independent source-backed task/application questions and two obstacle/listening questions. Result and manipulation validity are in evaluation.md. The timer mutation left an equivalent early explanation in place, so it cannot count as a missed valid defect.

## Run 2

The timer mutation moves both explicit first-fire explanations to the end. The independent evaluator checked its validity before readers started. Other page copies, factual requirements and four task questions are unchanged. Fresh readers examine task paths in article order before later reference and explicitly consider consequential information introduced only after an action. Intact controls and injected copies are mixed, with pairs kept in separate contexts.

Actual execution limit: reader D printed each full article before reasoning through the main path (and also printed input.rendered_article for the first case). Reader E printed input.rendered_article for its first case before intended chunking, then used metadata-only reads. These are retrospective agent ordering reviews, not prospective first-use observations; the requested sequence is not presented as achieved human behavior. Neither run is a human usability or read-aloud playback test. No result here proves another model/reviewer process will behave the same way.

## Comparison baseline

A separate fresh reader answered the same four factual tasks on the factual-correction-only original copies. These were whole-article lookup/comprehension reviews, not a controlled comparison of first-use speed or voice. Human listening uses unlabelled pairs with identical factual requirements, and remains a separate acceptance condition.
