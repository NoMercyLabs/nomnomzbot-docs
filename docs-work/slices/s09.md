## Flows

### 1. Turn text to speech on and pick a voice
1. Open "Text to speech" in the sidebar (group "Music and voice"). The page opens on the "Overview" tab. A badge says "Text to speech is on" or "Text to speech is off".
2. To turn it on or off: open the "Rules" tab. In the "Speaking" panel, use the switch "Read messages aloud". It saves at once.
3. Open the "Voices" tab. The "Pick a voice" panel lists voices grouped by language. Use "Search voices" or a language chip ("English", "Dutch", ...).
4. Press the play button on a row ("Play sample") to hear it. The button changes to "Stop" while it plays.
5. Click the row to make it the channel voice. A check mark appears on the row. The "Channel voice" panel on the right shows the name, language, gender and provider.
6. Back on "Overview", the row "Voice" now reads "{voice} · {provider}".

### 2. Choose who may be heard and how much
1. Open the "Rules" tab.
2. In "Speaking", choose "Who may be heard" (Everyone, Twitch subscribers, VIPs, Moderators, Broadcaster).
3. Type a number in "Maximum characters" (1 to 500) and press Enter or leave the box. A wrong number shows an error line under the box and the old value stays.
4. Type seconds in "Cooldown" (0 to 3600) the same way.
5. In "Message rules", set "Minimum bits" (0 = none) the same way, and the switches "Censor profanity" and "Moderators approve first".
6. Under each setting a gray caption says "Default: ...". The button "Reset to defaults" (bottom of each panel) puts the rule settings back. It is disabled when nothing differs.

### 3. Let a channel point reward speak
1. Open the "Rules" tab and find "Rewards that speak".
2. Each reward is a row with its cost ("{count} points"). Switch a row on.
3. The bot then reads the viewer's own text of that reward aloud. (The rewards themselves are created elsewhere; the empty text is "No rewards yet. Create a reward first.")

### 4. Add a pronunciation rule
1. Open the "Pronunciation" tab.
2. Press "Add rule". The dialog "Add a pronunciation rule" opens.
3. Fill "Phrase" (what is written), "Say instead" (what the bot says) and "Match" ("Whole word, any case" or "Exact text").
4. Press "Add rule". The dialog closes and the rule appears in the list. If the same phrase and match already exist, the dialog stays open and says "A rule with this phrase and match already exists."
5. Press the play button on the row ("Hear the rule for {phrase}") to hear it in the channel voice. Use the pencil to edit and the trash to delete (a confirmation "Delete this rule?" asks first).

### 5. Use your own voice key (Azure or ElevenLabs)
1. Open the "Keys" tab.
2. Type the key in "Azure speech key" or "ElevenLabs key" and press "Save key". The toast says "The key is stored." and the box is emptied. The badge changes to "Key stored". The key is never shown again.
3. For Azure, fill "Azure region" (for example westeurope). It is saved when you leave the box.
4. On the "Rules" tab, in "Speaking", set "Voice source" to "My own key" and pick the provider. (The "Voice provider" list then offers only key providers.)
5. "Remove key" deletes a stored key.

### 6. Set how your channel name is spoken
1. Open the "Keys" tab, section "How to say the channel name".
2. Type the spelling (for example how the name sounds), press "Preview" to hear it, then press "Save spelling". The toast says "The spelling is saved." Empty text clears it.

### 7. Create a voice trigger (count a spoken word)
1. Open "Voice triggers" in the sidebar (group "Build").
2. Press "New voice trigger" (or "Make the first voice trigger" in an empty list). The dialog opens: "Pick a word to count when you say it. Keep the voice listener page open in Chrome."
3. Fill "Word to listen for". Optionally set "Start counting at" (to carry a count over from another bot), "Seconds between counts" (default 5) and a "Sticker" (one of your uploaded images).
4. Press "Create voice trigger". The row appears in the list as "Heard 0 times" (or the start value).
5. Press "Popout listener" (page header). A small window opens with the listener page. Keep it open in Chrome (not as an OBS browser source) and allow the microphone.
6. Say the word. The listener page marks it "Matched ..." and the count in the list and in "Heard so far" goes up. If a sticker is set it pops up on the stream overlay.

### 8. Edit or delete a voice trigger
1. Click a row in the list. The right pane opens the editor (address gets `?voice=...`).
2. The switch "Enabled" saves at once. Other fields ("Word to listen for", "Seconds between counts", "Sticker") are a draft: the footer counts "{count} unsaved changes". "Save changes" sends them; "Discard" returns to the saved values.
3. "Delete" asks "Delete {name}?" and says the count is lost but the sticker image stays in your files.

### 9. Link VTube Studio
1. Open "VTube Studio" in the sidebar (group "Live"). The "Connection" tab opens. The status line starts as "The link to VTube Studio is switched off".
2. Turn on "Link to VTube Studio", choose "Connection type" ("Direct" or "Bridge"), check "Address", and choose the events. Press "Save".
3. Press "Authorize". The button reads "Waiting for approval" and the help says "Click Allow in VTube Studio. This waits up to a minute." Click Allow in VTube Studio.
4. The "Approval" row changes to "Approved. The bot keeps the key." and the status goes to "Approved, not connected yet", then "Connected" (green).
5. Only the owner (Broadcaster) sees the buttons "Save", "Authorize" and "Rotate bridge token"; the form fields are locked for others.

### 10. Control the model
1. With the link "Connected", open the "Hotkeys" tab. Pick a "Model" and press "Load model" to load it. Pick a "Hotkey" and press "Trigger" to fire it.
2. Open the "Expressions" tab. Pick an "Expression" and press "Activate" or "Deactivate".
3. If the link is not connected, both tabs show "This shows once VTube Studio is linked." If VTube Studio does not answer, a toast says "VTube Studio did not answer. Check the connection."
4. The buttons need `vts:control` (moderators by default); the pickers show for everyone with read access.
