## User surface

Scope note. This slice is server controllers only. No dashboard label (en.json) was read here, so the "Real label" column names the route, not a screen word. The writer must take screen words from the dashboard slices. "Who may use it" gives the `[RequireAction]` key. The seeded level for each key comes from `ActionDefinitionSeeder.cs` (levels: Everyone 0, Subscriber 2, Vip 4, Moderator 10, LeadModerator 20, Editor 30, Broadcaster 40; `MFloor` keys default to Moderator but the broadcaster may lower them to Vip; `M` keys cannot go lower; community keys are Everyone). A channel can override a level inside the allowed range (ActionDefinitionSeeder.cs:75-79, 33-37). Route base is `api/v1`; `{ch}` is the channel id.

## Flows

1. Open the Discord link (route flow, labels not read here). The user starts the Discord install (route `.../integrations/discord/callback/start`). Discord shows its install page. After approval the server sends the browser to the relay page and on to the dashboard Discord page (`/app/settings/discord`). On a failure the Discord page gets `discord_error` with a reason code: `invalid_state`, `access_denied`, `authorization_failed`, `credentials_unconfigured`, `token_endpoint_unreachable`, `token_exchange_failed`, `no_access_token`, `no_guild`, `guild_link_failed` (DiscordOAuthController.cs:131-295, 366-377). If no Discord app is set up, start returns `PROVIDER_NOT_CONFIGURED` (97-100).
2. Turn Discord notifications on (needs both sides). The server admin approves (server-consent) and the streamer turns on their side (streamer-enabled); withdrawing the server consent halts notifications until re-approved (DiscordController.cs:82-126). Then the user lists triggers, creates a rule with a message, and previews it (238-303).
3. Moderate from the chat page. Operator sends a message as themselves or as the bot; deletes a line (attributed to them); changes chat modes (slow mode, followers only, and so on, written to Twitch); sends an announcement (ChatController.cs:379-689).
4. Ban a person. Look the login up (`community/lookup`), then POST `.../ban` with a reason. Twitch bans first; only then is the local record written (CommunityController.cs:1399-1444). Unban removes the local record after Twitch accepts (1467-1481).
5. Install or share a bundle. Export gives a ZIP; Inspect shows the manifest and issues without installing; Import installs with the conflict policy (default Rename); Uninstall first reads the blast radius, then removes exactly what that bundle installed (BundlesController.cs:41-153).
6. Delete a command. Read the blast radius first; the delete is refused while anything still runs the command (CommandsController.cs:165-206).
7. Enter a channel you moderate without the bot ("Moderator mode"). The server checks your Twitch moderator list live, creates a light channel, and gives you the Moderator role (ChannelsController.cs:305-392).
