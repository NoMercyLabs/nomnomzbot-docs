## Flows

### Make a channel command
1. In the sidebar group "Build", open "Commands". The tab "Channel commands" is shown; the list is sorted "Most used".
2. Press "New command" (top right). The dialog "New command" opens.
3. Type the "Name" (for example `hello`). A leading `!` is removed and capitals become lower case. Spaces are refused by the bot.
4. Under "What it does" pick "Sends a reply". Type the "Reply".
5. Optional: open the trigger part ("Prefix", "Match") if the default `!` + "Starts with" is not wanted.
6. Press "Create command". The dialog closes and the new command opens in the editor with "Who can use it" at "Everyone" and no cooldown. If the bot refuses (name already exists, empty reply, unknown placeholder, limit reached) the red text stays in the dialog.
7. In the editor set "Who can use it", open "Trigger and cooldowns" for "Chat cooldown (seconds)" and "Per-person cooldown (seconds)". The footer shows "{count} unsaved changes". Press "Save changes". Chat can use the command.

### Make a random-reply command
1. "New command" then "What it does" = "Sends a random reply".
2. Fill the first reply box "Reply 1"; "Add a reply" adds more boxes; "Remove reply {number}" is greyed out while only one box is left.
3. "Create command". In the editor the "Random replies" row shows "{count} replies" and "Edit replies" reopens the list in a dialog. "Use these replies" puts the dialog's list in the draft; "Save changes" stores it.
4. Optional in that dialog: under "Or start from a list you already have" press "Use the replies of !{name}" to copy another command's list.

### Switch a command on or off
1. In the list, flip the switch on the row, or open the command and flip "Enabled". Both save at once. A switched-off command keeps its row, with the chip "Off".

### Duplicate a command
1. Open the command, press "Duplicate" in the footer. A copy named `<name>-copy` opens, switched off. Rename or edit it and switch it on.

### Delete a command
1. Open the command, press "Delete".
2. If a reward, timer, event response or the like still runs the command, the editor shows "Still used by ..." and stops. Move or remove those first.
3. Otherwise the dialog "Delete !{name}?" opens. Press "Delete command". The panel closes and the row is gone.

### Reset a preset command
1. Open a command that came from a preset (the button "Reset to preset" is only there for those). Press it.
2. The dialog lists what changes (for example "Reply", "Who can use it"), or says nothing changes. Press "Reset to preset".

### Change a built-in (system) command
1. Open "Commands", tab "System commands" (needs write rights). Search by word if needed.
2. Click a row. The editor opens read-only with "Default: ..." hints.
3. Press "Customize". The reply boxes, "Who can use it", both cooldowns and "Read it aloud" unlock.
4. Edit, then "Save changes". A box whose value equals the default is stored as "no override".
5. A "Back to default" button beside a field puts that one field back at once, without Save.
6. "Reset to default" (footer) lists what will be lost and puts the whole command back, including turning it on again.
7. A command marked as data-rights says it always answers; "Customize" is greyed out.
8. To stop a built-in answering, flip the switch on its row ("Answers in chat" inside the editor). An always-on command has no switch.

### Move copies of system commands out of the channel list
1. When the list shows "{count} of {total} channel commands repeat a system command...", press "Move copies to system".
2. The dialog "Move {count} copies to system?" names the commands. "Remove copies" deletes them one by one.

### Link a Discord server
1. Open Settings, then "Discord" (Connections group).
2. With no server linked the card "Discord server" shows what the bot does and the button "Add the bot to your server". Press it. A pop-up opens on Discord's own page; pick the server there and allow the bot.
3. When the pop-up ends the page reads the link again. Success shows the server name with the badge "Linked and ready". A failure shows the card "The bot was not added to your server" with the reason, "Try again" and "Dismiss".
4. If the badge says "The bot is not in the server", press "Check again" after adding the bot.

### Turn on a Discord notification
1. On the "Notifications" card (appears once the bot is in the server) click "Set up" on the event row, for example "Stream goes live".
2. A side panel opens, filled with the ready message and, for go-live, the ready embed. Pick the "Discord channel" (a fitting one is chosen for you), optionally a "Ping role", and edit the "Message" and the "Embed" fields.
3. Press "Preview" to see the bot's own rendering (this also saves the rule). Press "Save". The row now says "On" and the button says "Edit".
4. "Recent posts" lower on the page shows each attempt with "Posted", "Failed" or a reason.
5. To pause one event: open it, switch off "Send this notification", "Save". To pause everything: switch off "Post to this server" in the Discord server card.
6. To delete the rule: "Remove" on the row, then "Remove rule".

### Add a self-assign role
1. On "Self-assign roles" press "Add role". Pick the "Discord role" (the live role is not in the list), keep or change the "Display name", and set "Viewers can pick this role" and "Send a direct message". "Save".
2. Edit the saved role: pick a "Button channel" and press "Post button" to place the opt-in button message in Discord. "Remove role" asks "Remove this role? ..." with "Keep" / "Remove".

### Live role
1. On the "Live role" card pick a "Role" and leave "Give the role while live" on. "Save". While the stream is live the role is applied to your own Discord account ("Applied right now"); the box is then locked.
2. "Remove rule" deletes the rule (hidden while the role is applied).

### Take the bot out of a server
1. In "Discord server" press "Disconnect server". The dialog "Disconnect {name}?" lists what stops working. Press "Disconnect".
2. "Withdraw approval" (only while approved) stops posting without deleting anything. The badge turns to "Waiting for the server admin to approve". The page has no button to approve again; "Use another server" runs the install again (see Traps).
