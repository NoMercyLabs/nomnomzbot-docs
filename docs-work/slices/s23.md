## Flows
### Turn on text to speech and pick a voice
1. Open "Text to speech" in the left menu. The page opens on the "Overview" tab. It shows "Text to speech is on" or "Text to speech is off" (tts/i18n/en.json:5-6).
2. Open the "Rules" tab. Switch "Read messages aloud" on (en.json:128-131). Pick "Who may be heard" and set "Maximum characters" (en.json:142-156).
3. Open the "Voices" tab ("Pick a voice"). Use "Search voices" or the "Language" filter. Press "Play a sample of {voice}" to hear the stored clip. The clip needs no wait on the provider (ITtsVoiceSampleStore.cs:14-17).
4. Click a row to make it the channel default (en.json:67). The page then shows "Channel voice".
5. Add the speaker overlay to OBS once. The page says: "Added to OBS from the Required overlays on the OBS page." (en.json:49).
6. Back on the "Overview" tab, "Spoken history" fills as the bot speaks (en.json:14-21).

### Use your own voice key
1. Open the "Keys" tab ("Keys and name").
2. Pick Azure or ElevenLabs. Paste the key. For Azure, type the "Azure region" (placeholder `westeurope`). Press "Save key" (en.json:205-217).
3. The tab then shows "Key stored". The key is never shown again; it says "A key is stored. Type to replace it." (en.json:211-216).
4. On "Speaking", set "Voice source" to "My own key" (en.json:132-137).
5. "Remove key" falls back to the platform key (ITtsConfigService.cs:58).

### Add a pronunciation rule
1. Open the "Pronunciation" tab. Press "Add rule".
2. Fill "Phrase", "Say instead", and "Match" ("Whole word, any case" or "Exact text"). Press "Save rule" (en.json:178-189).
3. A rule with the same phrase and match shows "A rule with this phrase and match already exists." (en.json:190).
4. Edit and delete from the row. Delete asks "Delete this rule?" (en.json:198-200).
5. On the "Keys" tab, "How to say the channel name" sets how your own login is spoken. Press "Save spelling" (en.json:222-226).

### Tune the trust policy
1. Open settings, then "Trust policy".
2. The page shows six groups: Score weights, Growth speed, Boosts and multipliers, Penalties, Tier ceilings, Heat (trust-policy/i18n/en.json:12-36). Each field shows "Default {value}".
3. Change the weights. The page shows "Total {sum} of 1" (en.json:9).
4. Press "Save". A refused save names the field and says why, for example "The four score weights must add up to exactly 1." (en.json:140-141 and TrustPolicyViolation.cs:22).

### Connect a supporter service
1. Open "Supporters", then the sources list "Services your supporters use".
2. Press "Set up" on a service (for example Ko-fi). Only a broadcaster may do this.
3. For a webhook service, the dialog shows "Address to give the service". Paste that address into the service's webhook settings (supporters/i18n/en.json:46-47).
4. Paste the "Secret or token". The page says: "The secret goes to the bot and is never shown again." (en.json:48).
5. For Patreon and Shopify, connect the account under Integrations first. Otherwise the dialog says "No {name} account is connected yet. Connect it under Integrations first." (en.json:49; PatreonSupporterSource requires OAuth: PatreonSupporterSource.cs:37).
6. Keep "Receive events" on and press "Save". The row then shows "Connected" or "Paused" and "Last event {time}" (en.json:56,90-96).
7. "Remove" deletes the secret and stops listening. Tips already recorded stay (en.json:88).

### Add a custom overlay and show it in OBS
1. Open "Overlays". Press "New overlay".
2. Type a "Name". Pick the "Code language": "Vue" or "Plain HTML, CSS and JavaScript". It cannot change later (overlays/i18n/en.json:25-33).
3. Press "Create overlay". Use "Edit code" to write it. Saving compiles it. The page says "Saved and compiled. The overlay now runs this version." (en.json:59).
4. Open "Set up {name} in OBS". Copy the address. In OBS add a Browser source and paste it. Enter the width and height. Set the two boxes as shown (en.json:86-118).
5. The detail shows "A browser source is open" once OBS loads it (en.json:157).
6. If the address leaks, rotate the overlay token. The old address works for 15 minutes more (WidgetService.cs:44).

### Make an API key for a tool
1. Open settings, then "API and devices". Press "New key".
2. Type a "Name". Tick the "Allowed actions" the tool needs. Optionally pick "Pipelines it may start" ("Pick none to allow every pipeline."). Optionally set "Ends on" ("Leave empty for a key that does not end.") (api-devices/i18n/en.json:36-45).
3. Press "Make key". The page shows the key once. Press "Copy key", then "I copied it" (en.json:47-52).
4. To change a key later, use "Make a new secret". The old secret stops at once (en.json:53-58).
5. "Revoke key" ends the key for good. A paired device is unpaired (en.json:60-66).

### Pair a device without copying a key
1. In "Pair a device", type a "Device name" and press "Make code" (en.json:70-73).
2. The page says: "Type it into the device before {time}. It works once." (en.json:74). The code is 8 characters and lasts 5 minutes.
3. Or let the device ask first. The device shows a short code. Type it in "Code shown on the device" and press "Approve device" (en.json:76-80). The page says "Device approved. It appears in the key list."

### Connect VTube Studio
1. Open "VTube Studio", tab "Connection".
2. Pick "Connection type": "Direct" or "Bridge". Check "Address" (default `ws://localhost:8001`). Choose "Events to listen to" (the last three are high volume). Switch "Link to VTube Studio" on. Press "Save".
3. Press "Authorize". The page says "Waiting for approval". In VTube Studio click Allow within about a minute (en.json:44-46).
4. The status then reads "Connected" (vts/i18n/en.json:12-18).
5. On "Hotkeys" pick a model and a hotkey, then "Trigger". On "Expressions" pick one and "Activate" or "Deactivate".
