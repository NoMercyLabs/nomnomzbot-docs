## Flows
These are API flows. This slice holds controllers only. The button labels live in the dashboard slices.

1. Set up event responses. Call the preset catalog, pick an event type, then save the response with PUT. To go back to the default, POST reset. If the response is bound to a pipeline, command or action, the reset is refused until `confirm=true`. The user then sees the event type back at its seeded default.
2. Get the alert overlay URL. Call GET overlay. The first call creates the `alerts` widget and returns the OBS browser-source URL. Call alert-queue to see recent alerts and whether the overlay is connected.
3. Run a giveaway. Create (draft), open, close, draw. If a winner forfeits, redraw that winner. Entries and winners are listed. Delete first asks the blast-radius route and shows counts. For a code prize, create a code pool, add codes, and attach the pool. Codes show only masked. The broadcaster can reveal one winner's code if the whisper failed.
4. Connect Spotify or YouTube. Optional for Spotify: save your own client id and secret. POST connect returns an authorize URL. The user approves in a popup. The provider calls the callback. The browser lands on `/oauth-relay`. Status then shows connected. Disconnect asks blast-radius first.
5. Moderate the song queue. Read the queue. Close requests with `requests-open`. Remove, promote, move or ban a song. Block a track so it cannot be requested again. Skip, pause, resume.
6. Ban across channels. Pick `Scope = all_moderated` on ban, or use the mass-ban preview, then submit targets. Live channels hold the batch until `!allow massban`, or the stream ends. Check the batches report for banned, failed, retrying and waiting counts.
7. Deal with held AutoMod messages. List the queue. Approve, or deny with an optional timeout or ban. A deny whose follow-up failed returns the follow-up error in the message and still returns the denied item.
8. Use a shoutout. POST shoutout (or accept a suggestion). The result path is `sent`, `announce_only`, `queued`, `already_queued` or `already_announced`. A custom line for one person is saved in shoutout-overrides.
9. Export or import channel history. Export downloads a `.jsonl` file. Import it on another deployment, then run replay and rebuild-projections so the data reaches the read models.
