## User surface
- ViewerDashboardLink.vue: a ghost button in the dashboard frame that links to `/app` (the viewer pages), labeled by `frame.viewerDashboard`. It shows only when a channel is selected and the "view as" preview is off.
- ReadAloudCors.cs: the CORS policy `PublicReadAloud` for the public read-aloud route; the allowed origins come from configuration (`AllowedOrigins`). Covered by /reference/audio/read-aloud-api.
- ReadAloudOriginGate.cs: refuses a read-aloud request whose Origin is not an allowed site (403). Covered by /reference/audio/read-aloud-api.
- ScriptRunClock.cs: the clock of one code-script run. Only the script's own time counts against the 8 s run budget; the timer pauses while a host call (for example `nnz.api.tts.speak`) waits. Each host call has its own deadline (15 s by default); past it, that call returns null and `nnz.lastError` reports `upstream_failed`. The monthly script-time meter counts only the script's own time. The code-script pages that describe the run budget should say this when they are next reviewed.
