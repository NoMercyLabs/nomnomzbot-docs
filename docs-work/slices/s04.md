## Headline findings (read these first)
1. **The Games page is not live.** `GamesView.vue` is imported only by its own test (`dashboard/src/views/dashboard/games/__tests__/GamesView.spec.ts:21`). There is no games route file. `/app/games` opens the "Coming soon" page (router/dashboard.ts:74-127 has no games route; scaffold/route.ts:34-55 builds the coming-soon route; router/__tests__/gamesComingSoon.spec.ts:19-25 says so). The user guide must not describe the Games page as usable. The rows below for Games are marked "built, not routed".
2. **Giveaway "Claim window" help text is wrong.** Help says "Empty uses the default." The code has no default. Empty means no claim window, and winners are marked Claimed at once.
3. **Winner status shows a raw word.** The server sets a new winner to `drawn` (and a redraw to `redrawn`). The page has translations only for pending, fulfilled, claimed, forfeited, failed. A fresh winner shows the raw lowercase word.
4. **Pool codes cannot be added after creation** in these files, although the dialog says "You can add codes later."
5. **Viewer pages for Leaderboards, Points store and Games are "Coming soon"** (views/viewer/nav/route.ts:26-28), while the Economy page says leaderboards are "Visible to viewers" and the Store is "Things viewers buy".

## Flows

### Set up the channel currency (Economy)
1. Open the sidebar entry "Economy" (group "Loyalty"). The "Currency" tab shows if you may read it.
2. Switch "Currency on". It starts off, so viewers earn nothing until you switch it on.
3. Type the "Currency name" (required). Optionally fill "Plural name", "Starting balance", "Highest balance", "Decimal places", "Currency icon URL".
4. Press "Save currency". Without write access the button does not show. On a refused save a red line shows the bot's reason.

### Add an earning rule
1. Open the "Earning rules" tab. Press "New rule".
2. Pick a "Source" (only sources with no rule are listed; if all eight have one the box says "Every source has a rule").
3. Type "Amount earned". For chat and watch time you can fill "Seconds per payout".
4. Press "Save rule". The row shows the amount ("1 point" / "5 points") and "every N seconds". Use the switch on the row to turn it on or off.
5. To change a rule press the edit icon. The source cannot change. To remove it press the trash icon and confirm "Delete rule".

### Change or freeze one viewer's balance
1. Open the "Balances" tab. Type in "Search viewers" if the list is long.
2. Press the coin icon on the row ("Adjust the balance of {name}").
3. Type a whole "Amount" (minus takes away) that is not zero, and a "Reason". Press "Adjust balance".
4. To stop a wallet from earning or spending, use the switch on the row ("Freeze the wallet of {name}").

### Make a savings jar and invite a channel
1. Open "Savings jars". Press "New jar". Type "Jar name"; optional "About this jar", "Goal", "Jar icon URL", "Take-out cap per channel". Press "Create jar". The jar starts open.
2. To close or open a jar use its switch. To invite another channel press the person-plus icon, type its "Channel ID", pick "Role", set caps if wanted, press "Send invite".
3. A jar cannot be renamed or edited in this dashboard: the row has no edit button (SavingsJars.vue:118-145).

### Add a store item
1. Open "Store". Press "New item".
2. Type "Item name" and the "Effect kind" (free text). Set "Cost", "Who can buy", the "Command or pipeline to run", and any limits. Press "Save item".
3. Use the switch to turn an item on or off, the edit icon to change it (the effect kind is locked), the trash icon to delete it.

### Add a leaderboard
1. Open "Leaderboards". Press "New leaderboard".
2. Choose "Ranks by", "Period", "Over". If "Over" is "One jar", choose a "Jar". Set "Places shown" and "Visible to viewers". Press "Save leaderboard".
3. A leaderboard row has no on/off switch, only edit and delete.

### Edit what the bot says for an event
1. Open "Event responses". Pick an event in the list (search with "Search events").
2. Check "Enabled".
3. If the event still follows the platform default, the card lists default lines. Press the edit icon on one to copy it as your own text. The help line then says "Saving makes this your only line: it replaces the default lines."
4. Change "Your line". Use the names listed under "You can use:". Optionally switch "Read it aloud".
5. Press "Save changes". Press "Discard" to drop edits.
6. To go back to the platform lines press "Reset to default" and confirm. The dialog lists your own line and any pipeline binding that will be lost.
7. To run a pipeline instead, switch "Reaction" to "Pipeline" and pick a command, pipeline or action.

### Run a giveaway
1. Open "Giveaways". Press "New giveaway". Fill the dialog (see the user surface table). Press "Create giveaway". It starts as "Draft".
2. On the row press "Open for entries". Status becomes "Open".
3. Viewers type the keyword (default `!enter`) in chat, or are counted as active viewers.
4. Press "Close entries", then "Draw winners" (or "Draw winners" straight from Open).
5. The "Winners of {title}" card lists winners. Press the rotate icon to draw a new winner for one of them.
6. To change a giveaway press the pencil icon (only Draft or Closed).

### Make a code pool for a code prize
1. Press "New pool" in "Code pools". Type "Name", paste "Codes" one per line, press "Create pool".
2. In the giveaway dialog set "What winners get" to "A code from a pool" and choose the pool.

### Run a chat game (not available: page is "Coming soon")
The steps below exist in the code only. Start a game from "Start a game", cancel it from "Running now" (entry fees are refunded), set mini-games in "Mini-games". Do not write these steps into the guide until the Games route is built.
