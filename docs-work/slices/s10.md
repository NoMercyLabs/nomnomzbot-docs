## Flows
1. Change the command prefix and language (Settings, "Bot basics").
   1. Open Settings, then "Bot basics". The card is titled "Commands and language".
   2. Type in "Command prefix" (1 to 5 characters, no spaces) and choose a "Language" and "Timezone".
   3. The "Save" button stays off until something changed and every field is valid. "Discard changes" puts the stored values back.
   4. Click "Save". A toast says "Basics saved." or "The basics could not be saved." (BasicsView.vue:218-240,371-377).
2. Change the reply tone (Settings, "Bot personality").
   1. Open "Bot personality". The card is titled "Reply voice".
   2. Click one of the tones (Informative, Friendly, Sassy, Hype, Chill). It saves at once. There is no Save button.
   3. If the bot refuses, the pick rolls back and a message goes to the error inbox (PersonalityView.vue:12-13, comment).
3. Set up greetings and streaks (Settings, "Engagement triggers").
   1. Switch on "First message ever", "Back after a break" and/or "Watch streaks". The help text under each says the default.
   2. Set "Time between greetings" in seconds.
   3. Under "Streak milestones" click "Add milestone", type a count, or the bin button to remove one.
   4. Click "Save changes". "Reset to defaults" only fills the form; nothing is sent until you save.
4. Make an API key (Settings, "API and devices").
   1. Click "New key". Fill "Name", tick "Allowed actions", optionally pick "Pipelines it may start", optionally set "Ends on".
   2. Click "Make key". A dialog "Key for {name}" shows the key once.
   3. Click "Copy key", then "I copied it". After it closes the key cannot be shown again; the bot keeps only a fingerprint.
   4. To replace a key: click the rotate button on its row, confirm "Make new secret". The old secret stops at once.
5. Pair a device (Settings, "API and devices", "Pair a device").
   1. Device asks you: type the code the device shows into "Code shown on the device", click "Approve device". The text "Device approved. It appears in the key list." shows.
   2. You ask the device: type "Device name", click "Make code", type the shown code into the device before the shown time. It works once.
6. Set the AutoMod filters (Settings, "AutoMod filters").
   1. Switch on the filters you want and fill the lists (one entry per line) and numbers.
   2. Click "Save" in the page header. A toast says "AutoMod saved."
   3. For Twitch's own filter, pick a level per category and click "Save Twitch levels" (separate button).
7. Add a chat filter (Settings, "Chat filters").
   1. Click "New filter". The editor replaces the list.
   2. Fill "Name", pick "What it checks", fill the field that shows, pick "When a message matches" and "Never filter".
   3. Optional: type a "A sample chat message" and click "Try message".
   4. Click "Save filter". A missing name, pattern or term, or a timeout under 1 second, marks the field and stops the save.
8. Block a word on Twitch (Settings, "Blocked terms").
   1. Type in "Word or phrase to block" and click "Block". It appears under "Blocked now".
   2. "Unblock" removes it with no confirm.
9. Set the escalation ladder (Settings, "Escalation").
   1. Switch on "Escalation ladder".
   2. Edit the "At offense" numbers, pick Warn, Timeout or Ban per step, set the "Timeout length".
   3. Click "Save" in the header. If the bot refuses a row, the message shows under that row.
10. Bring in outside data (Settings, "Custom event feeds").
    1. Click "New feed". Fill "Name" and "Event name"; pick how the data arrives.
    2. Fill the "Address" (not for a push feed), the "Secret" if needed, and "Add field" rows (name plus path).
    3. Click "Make feed". Use the lightning button on the row to open "Test {name}" and click "Send test event".
11. Delete the channel (Settings, "Channel management").
    1. Click "Delete channel". The bot counts what the delete removes and a dialog lists it.
    2. Type the channel name and confirm. A notice says the channel can be brought back until a date.
    3. To undo, click "Bring the channel back" while the page is open (other deleted channels also list there).
