# Documentation map: the NomNomzBot user guide

**Scope:** The user guide for streamers and their moderators who do not write code. It covers everything a person uses in the dashboard, the first-run setup and the Docker install, plus lane E, a draft of the code scripts and the SDK for people who write a little code. Settled by the owner on 2026-10-28 in `docs-work/scope.md`.
**Excluded:** The list below, with a reason each. Also out of this guide: the API reference, contributor documentation and the platform-operator pages. They come in a later lane.
**Audience:** Tier one is a streamer or a moderator who opens the dashboard and does not write code. Lane E ("Code and SDK (Draft)") is for a person who writes a little code in the dashboard's script editor.
**Destination:** The existing documentation site in this repository. A page is the file `src/content/reference/en/<area>/<page>.mdx` and is routed at `/reference/<area>/<page>`. The guide start page is `/reference/overview` (file `src/content/reference/en/overview.mdx`). The sidebar order is `src/lib/nav-structure.ts`, one group per area.
**Conventions:** `docs-work/page-conventions.md` (rules for every page), `docs-work/ledger.md` (who owns which concept) and `docs-work/lanes.md` (the writer queues). The product repository is read only; every claim on a page rests on a file and line that the writer keeps in the fact-check file, never on the page.

## Notes on this map

- The user's own page list yields about 70 pages. Each page holds one topic, so the count is above the 45 to 60 first estimate. A topic that is small is one page with sections, never two pages.
- A path in Covers is a file or a directory in the product repository. More than one page may name the same directory when each page owns a different part of it; the Job column says which part.
- Features that the dashboard shows as "Coming soon", or that have no dashboard page, are named in the Job of the page that owns them. No page is invented for them. They are: Library, Gallery and Games (sidebar entries that open the Coming soon page), the four viewer pages Now playing, Leaderboards, Points and store, and Games, and the StreamElements import (an API route, no dashboard page).
- Billing is described as an account screen of NoMercy Labs plans. The guide never presents a paid plan as the normal way to use NomNomzBot.
- The pilot reference page is `/reference/commands/create-a-command`. It is the first page written; the other pages are matched to it.
